複数のレポートで同じ計算式を使う

純売上高や粗利率の計算式を DML で定義すると、月別と地域別のレポートで共通して使えます。生成された SQL を確認したり、既存のレポートと同じデータで実行して結果を比べたりできます。

ドキュメントを読む例を使って学ぶ

返金額を引くと、どの数字が変わる？

月別レポートは注文を月ごとに、地域別レポートは地域ごとに集計します。どちらも同じ純売上高を使います。モデルの式を 1 行変更し、元の 2 つのクエリをもう一度実行します。

変更前の式
純売上高: SUM({注文金額})
返金額を引いた式
純売上高: SUM({注文金額}) - SUM({返金額})
レポート月または地域変更前返金額の控除後
月別1 月10090
月別2 月230200
地域別東部250210
地域別西部8080

返金はどちらも東部で、1 月に 10、2 月に 30 でした。西部には返金がなく、合計は 80 のままです。

モデルと 2 つのクエリを見る 
dialect: duckdb
売上注文:
  type: dataset
  table: orders
  dimension: [注文番号]
  columns:
    注文番号:
      abbr: order_id
    dt_month:
      abbr: report_month
    地域:
      abbr: region
    注文金額:
      abbr: amount
    返金額:
      abbr: refund
  measures:
    純売上高: SUM({注文金額})

前月の純売上高:
  type: measure
  formula: '{純売上高: pp}'

月別レポート

SELECT dt_month, AGG(純売上高) FROM MODEL GROUP BY dt_month ORDER BY dt_month

地域別レポート

SELECT 地域, AGG(純売上高) FROM MODEL GROUP BY 地域 ORDER BY 地域

2月と1月の純売上高を比べる

dt_month に2月を指定し、同じ指標に pp を付けると、前月の純売上高が得られます。返金額を差し引いた後の純売上高は2月が200、1月が90です。

SELECT AGG(純売上高), AGG(前月の純売上高) FROM MODEL WHERE dt_month='2025-02-01'
実行できるサンプルをダウンロード

展開したプロジェクトの net-revenue フォルダーで次のコマンドを実行します。

dmlc -q setup.sql
dmlc -q --model=model.dml monthly.sql
dmlc -q --model=model.dml regional.sql
dmlc -q --model=after-refunds/model.dml monthly.sql
dmlc -q --model=after-refunds/model.dml regional.sql
dmlc -q --model=after-refunds/model.dml previous-month.sql
