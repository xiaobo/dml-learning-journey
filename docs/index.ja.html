複数のレポートで同じ計算式を使う

純売上高や粗利率の計算式を DML で定義すると、月別と地域別のレポートで共通して使えます。生成された SQL を確認したり、既存のレポートと同じデータで実行して結果を比べたりできます。

ドキュメントを読む例を使って学ぶ

返金額を引くと、どの数字が変わる？

月別レポートは注文を月ごとに、地域別レポートは地域ごとに集計します。どちらも同じ純売上高を使います。モデルの式を 1 行変更し、元の 2 つのクエリをもう一度実行します。

変更前の式
net_revenue: SUM({amount})
返金額を引いた式
net_revenue: SUM({amount}) - SUM({refund})
レポート月または地域変更前返金額の控除後
月別1 月10090
月別2 月230200
地域別東部250210
地域別西部8080

返金はどちらも東部で、1 月に 10、2 月に 30 でした。西部には返金がなく、合計は 80 のままです。

モデルと 2 つのクエリを見る 
dialect: duckdb
Sales:
  type: dataset
  table: orders
  dimension: [order_id]
  columns:
    order_id:
    report_month:
    region:
    amount:
    refund:
  measures:
    net_revenue: SUM({amount})

月別レポート

SELECT report_month, AGG(net_revenue) FROM MODEL GROUP BY report_month ORDER BY report_month DESC

地域別レポート

SELECT region, AGG(net_revenue) FROM MODEL GROUP BY region ORDER BY region
