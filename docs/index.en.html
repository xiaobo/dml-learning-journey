Use the same formula across reports

Define net revenue or gross margin in DML and use it in monthly and regional reports. Inspect the generated SQL, or run it on the same data as an existing report and compare the results.

Read the docsLearn with examples

What changes when you deduct refunds?

The monthly report groups orders by month. The regional report groups them by region. Both use net revenue. Change one line in the model and rerun the original queries.

Original formula
net_revenue: SUM({amount})
Deduct refunds
net_revenue: SUM({amount}) - SUM({refund})
ReportMonth or regionBeforeAfter refunds
MonthlyJanuary10090
MonthlyFebruary230200
RegionalEast250210
RegionalWest8080

Both refunds were in the East: 10 in January and 30 in February. The West had no refunds, so its total stays at 80.

  measures:

Monthly report

SELECT report_month, AGG(net_revenue) FROM MODEL GROUP BY report_month ORDER BY report_month DESC

Regional report

SELECT region, AGG(net_revenue) FROM MODEL GROUP BY region ORDER BY region
