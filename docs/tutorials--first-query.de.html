Erste Modellabfrage kompilieren

Inhalt dieser Seite
  • Compiler identifizieren
  • Modell definieren
  • Abfrage schreiben
  • Abfrage kompilieren
  • Ergebnis prüfen

Wir erstellen ein Vertriebsmodell und kompilieren eine Abfrage, die Summen nach Region zurückgibt. Dazu benötigen wir eine installierte Version von dmlc.exe und ein Arbeitsverzeichnis mit Schreibzugriff. In diesem Tutorial kompilieren wir SQL ohne Datenbankverbindung.

Compiler identifizieren #

Installieren Sie dmlc.exe und fügen Sie das Verzeichnis, in dem die ausführbare Datei liegt, zu PATH hinzu. Öffnen Sie PowerShell und speichern Sie den Pfad zur ausführbaren Datei, bevor Sie ein Arbeitsverzeichnis erstellen.

$dmlc = (Get-Command dmlc.exe).Source
& $dmlc --version

Notieren Sie Version und Build-Zeitpunkt. So können Sie später feststellen, mit welchem Compiler Ihr Ergebnis entstanden ist.

Erstellen Sie nun ein neues Verzeichnis für die Dateien.

New-Item -ItemType Directory -Path first-query
Set-Location first-query

Die Eingabeaufforderung endet jetzt mit first-query.

Modell definieren #

Speichern Sie den folgenden Inhalt als model.dml.

dialect: mssql

Verkaufspositionen:
  type: dataset
  table: TABLE_SALES
  dimension: [VerkaufspositionID]
  columns:
    VerkaufspositionID:
      abbr: id
    Region:
      abbr: region
    Verkaufsbetrag:
      abbr: amount
  measures:
    Umsatz: SUM({Verkaufsbetrag})
    Verkaufsanzahl: COUNT(1)

DurchschnittsumsatzJeVerkauf:
  type: measure
  formula: 'DIVIDE({Umsatz}, {Verkaufsanzahl})'

Verkaufspositionen definiert pro VerkaufspositionID genau eine Quellzeile. Umsatz und Verkaufsanzahl aggregieren diese Zeilen. DurchschnittsumsatzJeVerkauf teilt das erste Ergebnis durch das zweite.

Prüfen Sie das Modell nun mit dem Linter.

& $dmlc --lint model.dml --json
$LASTEXITCODE

Der Prozess endet mit dem Exitcode 0. Wenn der Linter einen Befund meldet, vergleichen Sie die gespeicherte Datei mit dem Modell oben, bevor Sie fortfahren.

Abfrage schreiben #

Speichern Sie den folgenden Inhalt als query.sql im selben Verzeichnis wie model.dml.

SELECT Region, AGG(Umsatz), AGG(DurchschnittsumsatzJeVerkauf)
FROM MODEL
GROUP BY Region

FROM MODEL wählt model.dml aus. Jede Ergebniszeile steht für eine Region.

Abfrage kompilieren #

Kompilieren Sie die Abfrage nun im strikten Modus.

& $dmlc --compile --strict query.sql --model=model.dml --json --artifacts=gen
$LASTEXITCODE

Die JSON-Ausgabe zeigt status: ok und exitCode: 0. Unter diagnostics stehen keine Fehler oder Warnungen. In data.sql sehen Sie, wie die Abfrage die Umsätze nach Region gruppiert und den Durchschnitt berechnet. Die Ergebnisspalten heißen Region, Umsatz und DurchschnittsumsatzJeVerkauf.

Der Compiler kann die Diagnosemeldung DATASET_GRAIN_UNVERIFIED als Hinweis ausgeben. Wir haben das deklarierte Modell kompiliert, ohne eine physische Tabelle TABLE_SALES zu prüfen.

Ergebnis prüfen #

Öffnen Sie die SQL-Datei unter gen. Suchen Sie die Aggregatausdrücke und die Gruppierung nach Region. Das Modell und die darauf zugreifende Abfrage sind jetzt vollständig. Den generierten SQL-Code können Sie nun prüfen.

Verwenden Sie zum Ausführen der Abfrage eine Datenbankverbindung, über die die deklarierte Quelltabelle verfügbar ist. Folgen Sie der Anleitung dmlc-CLI verwenden, um die Schlüssel an der verbundenen Datenbank zu validieren und die Abfrage auszuführen. Unter Grundkonzepte erfahren Sie, wie Modell- und Abfrageebene zusammenspielen.
