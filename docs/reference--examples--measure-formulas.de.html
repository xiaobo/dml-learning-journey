Jede Formel setzt voraus, dass die darin genannten Datensätze, Spalten und Kennzahlen vorhanden sind. Die Ausschnitte veranschaulichen die Formeln. Für einen ausführbaren Abnahmetest benötigen Sie ein vollständiges Modell und Testdaten.

Beispiele für Geschäftskennzahlen #

Finanzkennzahlen #

account_receivable:
    type: measure
    formula: |-
        {amount: {+f: {account: 'Accounts Receivable (A/R)'}}}

outstanding:
    type: measure
    description: All unpaid amounts (including not yet due)
    formula: |-
        {open_balance}

balance_due:
    type: measure
    description: Amounts due today or earlier
    formula: |-
        {open_balance: {+f: 'due_date <= date(current_date)'}}

Anzahl der Transaktionen #

number_of_invoices:
    type: measure
    formula: |-
        {number_of_transactions: {+f: {transaction_type : 'invoice'}}}

number_of_checks:
    type: measure
    formula: |-
        {number_of_transactions: {+f: {transaction_type : 'check'}}}

number_of_received_checks:
    type: measure
    formula: |-
        {number_of_checks: {+f: 'customer is not null'}}

Regeln für Namen, description: und abbr finden Sie unter Modell prüfen. Bei Fehlern helfen die Abschnitte P1 und P25 in der Fehlerübersicht.

Häufig verwendete Formeln #

Durchschnittswerte #

avg_invoice_value:
    type: measure
    formula: |-
        divide({amount: {+f: {transaction_type: 'invoice'}}}, {number_of_invoices})

Häufigkeiten #

avg_bill_frequency:
    type: measure
    formula: |-
        divide(sum({number_of_invoices: {+d: dt_date}}), datediff(day, min({dt_date}), max({dt_date})) + 1)

Durchschnittlicher Jahresumsatz #

annual_avg_revenue:
    type: measure
    formula: |-
        divide(sum({revenue: {+d: dt_year}}), distinctcount({dt_year}))
