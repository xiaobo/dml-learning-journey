診断と組み込み定義 #

  • エラーコード — 各コードの意味と推奨される対処方法。
  • トラブルシューティング — 症状と、つまずきやすい問題に付けられた安定した識別子。
  • システムマクロ — サンプルで使用する組み込みマクロの定義。

コマンドラインオプションについては、インストール済みの実行ファイルで dmlc --help と dmlc --advanced-help を実行し、出力を確認してください。
