これらのコードを使って、どの段階で失敗したかを特定し、対処方法を選びます。プロセスの終了コードに加え、診断情報と生成された SQL も確認してください。

パスの表示規則 #

ユーザーに表示されるファイルパスでは、どのプラットフォームでも スラッシュ（/）を使用します。

  • エラーメッセージでは、..\data や ../data などの入力は ../data に正規化されます。
  • ワークスペースのプレースホルダーを含むパスは <workspaceFolder>/relative/path の形式で表示します。プレースホルダー以降にはバックスラッシュを使用しません。
  • 解決済みのファイルシステムパスは、可能な限りカレントディレクトリからの相対パスで表示します。

エラーコードのカテゴリ #

カテゴリ 説明 CLI の終了コード
INVALID_INPUT 入力の検証に失敗しました。入力を修正して再試行できます。 64
VALIDATION ユーザーレベルの検証に失敗しました（構文解析結果は OK ですが、引数が無効です） 65
NOT_FOUND 要求されたリソースが見つかりません 66
CONFIG 構成エラー（構成がないか無効、接続 ID が不明など） 78
TIMEOUT 操作がタイムアウトしました。パラメーターを変更して再試行してください。 69
COMPILE コンパイルに失敗しました（構文エラーまたはモデルエラー） 2
EXECUTION 実行に失敗しました。再試行すると成功する場合があります。 70
INTERNAL 予期しない内部エラーです。このエラーは報告してください。 70
BLOCKED ポリシーまたは現在の状態により操作がブロックされました 77

エラーコード #

ファイル入出力エラー #

FILE_NOT_FOUND

  • カテゴリ：NOT_FOUND
  • コード：FILE_NOT_FOUND
  • よくある原因：ファイルパスが正しくない、ファイルが存在しない、またはファイルがワークスペースフォルダーの外にあります。
  • 推奨される対処方法：ファイルパスが正しく、ワークスペースフォルダー内を指していることを確認してください。
  • 例：File not found: /path/to/file.dml

FILE_ALREADY_EXISTS

  • カテゴリ：BLOCKED
  • コード：FILE_ALREADY_EXISTS
  • よくある原因：上書きを指定せずに、すでに存在するファイルを作成しようとしました。
  • 対処方法：新しい出力ファイル名を指定してください。既存ファイルを置き換えたい場合は、そのコマンドの上書きオプションを使います。
  • 例：File already exists: /path/to/file.csv

UNSUPPORTED_FILE_TYPE

  • カテゴリ：INVALID_INPUT
  • コード：UNSUPPORTED_FILE_TYPE
  • よくある原因：サポートされていないファイル形式を使用しようとしました。
  • 推奨される対処方法：サポートされているファイル形式（parquet, csv, xlsx）を使用してください。
  • 例：Unsupported file type: .txt. Supported types: .csv, .xlsx, .parquet

PATH_OUTSIDE_WORKSPACE

  • カテゴリ：BLOCKED
  • コード：PATH_OUTSIDE_WORKSPACE
  • よくある原因：ファイルパスがワークスペースフォルダーの外を指しています。これには、../ でフォルダーの外に出るパス、別のドライブ上の絶対パス、ワークスペース外を指すシンボリックリンクが含まれます。
  • 推奨される対処方法：ワークスペースフォルダー内を指す相対パスを使用してください。
  • 例：File path must be within workspace: ../outside/file.csv. Workspace folder: <workspaceFolder>
  • パスの表示：エラーメッセージや CLI の出力に表示されるパスでは、どのプラットフォームでもスラッシュ（/）を使用します。<workspaceFolder>/relative/path のようにプレースホルダーを含むパスも同様です。
  • 注記：CLI で WORKSPACE_FOLDER が設定されている場合、入出力ファイルはそのディレクトリ内に置く必要があります。

NO_SHEETS_IN_EXCEL

  • カテゴリ：INVALID_INPUT
  • コード：NO_SHEETS_IN_EXCEL
  • よくある原因：Excel ファイルにシートがないか、ファイルが破損しています。
  • 推奨される対処方法：シートを 1 枚以上含む有効な Excel ファイルを指定してください。
  • 例：Excel file has no sheets: /path/to/file.xlsx

接続エラー #

CONNECTION_NOT_FOUND

  • カテゴリ：CONFIG
  • コード：CONNECTION_NOT_FOUND
  • よくある原因：接続 ID が connections.json に存在しません。
  • 推奨される対処方法：利用可能な接続を一覧表示して有効な接続 ID を選ぶか、接続を connections.json に追加してください。
  • 例：Connection not found: production. Available connections: [dev, staging]

LIST_CONNECTIONS_ERROR

  • カテゴリ：EXECUTION
  • コード：LIST_CONNECTIONS_ERROR
  • よくある原因：データベースまたは構成のエラーにより、利用可能な接続を一覧表示できませんでした。
  • 推奨される対処方法：接続構成と、データベースにアクセスできるかどうかを確認してください。
  • 例：Failed to list connections: Connection refused

クエリ実行エラー #

EXECUTION_ERROR

  • カテゴリ：EXECUTION
  • コード：EXECUTION_ERROR
  • よくある原因：SQL エラー、データの問題、データベースの問題、またはモデル変更後に materialize のキャッシュが古くなったことにより、クエリの実行に失敗しました。
  • 推奨される対処方法：クエリの構文、データ型、データベースへの接続を確認してください。メッセージに materialize の semver が古いこと、または pls re-setup related model が示されている場合は、dmlc -s <model.dml> --connection=<id> を実行し、同じ --model の値でクエリを再試行してください。
  • 例：Execution failed: Column 'invalid_column' does not exist
  • 例（materialize が古い場合）：materialize abort: procedure PROC_M__CACHED_SALES is obsolete since semver (...) is different from expect: ..., pls re-setup related model

EXECUTION_INTERRUPTED

  • カテゴリ：EXECUTION
  • コード：EXECUTION_INTERRUPTED
  • よくある原因：ユーザーまたはシステムがクエリを中断しました。
  • 推奨される対処方法：クエリを再試行してください。
  • 例：Query execution interrupted

TIMEOUT_ERROR

  • カテゴリ：TIMEOUT
  • コード：TIMEOUT_ERROR
  • よくある原因：クエリの実行に時間がかかりすぎました。
  • 推奨される対処方法：timeoutSeconds パラメーターの値を大きくするか、クエリを簡素化してください。パフォーマンスを改善するために materialize の追加も検討してください。
  • 例：Query timed out after 30 seconds

コンパイルエラー #

COMPILE_ERROR

  • カテゴリ：VALIDATION
  • コード：COMPILE_ERROR
  • よくある原因：DML の構文エラー、モデルの検証エラー、SQL の生成エラー、または無効な修飾子の組み合わせです。たとえば、1 つの修飾子オブジェクト内で同じディメンションに +d と -d/-df を指定する場合です。言語仕様では、このような組み合わせに対して明示的にエラーを返すことになっています。修飾子の組み合わせと注意点 P79 を参照してください。
  • 推奨される対処方法：コンパイルエラーを修正し、model.dml がワークスペースフォルダーにあることを確認してください。error.details.generatedSql にある生成済みの SQL も確認してください。+d/-d/-df が競合する場合は、修飾子が互いに相殺されることに頼らず、意図する指定を 1 つに絞って明示してください。
  • 例：Compilation failed — see details.compilationErrors
  • 注記：今回確認したビルドでは、検証対象とした同一フィールド上の +d の競合でエラーは発生しません。評価段階を 1 つ明示し、生成された SQL を確認してください。指定が相殺されることに頼らないでください。

COMPILE_TIMEOUT

  • カテゴリ：TIMEOUT
  • コード：COMPILE_TIMEOUT
  • よくある原因：コンパイルの完了までに時間がかかりすぎました。
  • 推奨される対処方法：DML モデルを簡素化し、複雑さを抑え、タイムアウトを延長してください。
  • 例：Compilation timed out after 30 seconds

VALIDATION_ERROR

  • カテゴリ：VALIDATION
  • コード：VALIDATION_ERROR
  • よくある原因：宣言されたディメンション制約に違反しています。data.status と data.issues を確認してください。
  • 推奨される対処方法：無効なパラメーターまたは構成を修正してください。
  • 例：Declared dimension constraints were violated; see data.issues.

生成エラー #

MODEL_RESOLUTION_ERROR

  • カテゴリ：NOT_FOUND
  • コード：MODEL_RESOLUTION_ERROR
  • よくある原因：<FROM>.dml が SQL ファイルと同じディレクトリ、--model=<dir> の配下、モデルの検索パスのいずれにも見つかりません。ほかに、--model=acme.dml を FROM MODEL と併用した（ファイルと FROM が不一致で、終了コードは 65）、またはファイルのみを受け付ける操作にディレクトリを指定した可能性があります。
  • 推奨される対処方法：query、compile、validate コマンドには、対応する .dml ファイルを含むディレクトリ、または名前が FROM と一致するファイルを渡します。setup コマンドには .dml ファイルを渡します。
  • 例：model file "acme.dml" does not match FROM "MODEL" (expected "MODEL.dml").

FILTER_VALIDATION_ERROR

  • カテゴリ：VALIDATION
  • コード：FILTER_VALIDATION_ERROR
  • よくある原因：フィルターの構文エラー、または無効なフィールド名
  • 推奨される対処方法：フィルターのフィールド名または構文を修正します。
  • 例：Filter validation failed: invalid field 'dt_invalid'

ディメンションの検証エラー #

重複するキーと重なり合う範囲

  • カテゴリ：VALIDATION
  • コード：VALIDATION_ERROR。data.issues で問題の種類を確認します。
  • よくある原因：データセットのディメンション値の完全な組み合わせが複数回出現するか、範囲に基づく検索で範囲が重複する複数のソース行が一致する可能性があります。
  • 推奨される対処方法：ソースキー、データセットの dimension: のフィールドリスト、重複する範囲、またはソースデータを修正してから、--validate を再実行します。コンパイル済みの SQL に含まれる DISTINCT/GROUP BY を使っても、DISTINCTCOUNT 指標を使っても、pk(...) による検索結果が一意にならない問題は解消できません。
  • 例：Declared DML dataset dimension is not unique in dataset '注文明細' on this connection at validation time.

EXECUTION_ERROR

  • カテゴリ：EXECUTION
  • コード：EXECUTION_ERROR
  • よくある原因：検証クエリの実行に失敗しました。
  • 推奨される対処方法：接続構成と、データベースにアクセスできるかどうかを確認してください。
  • 例：Validation query failed: Connection refused

ワークスペースと操作のエラー #

NO_WORKSPACE

  • カテゴリ：BLOCKED
  • コード：NO_WORKSPACE
  • よくある原因：ワークスペースのフォルダーが設定されていないか、ワークスペースにアクセスできません。
  • 推奨される対処方法：ワークスペースのフォルダーを設定するか、ワークスペースへのアクセス権限を確認します。
  • 例：No workspace folder configured

INVALID_PARAMS

  • カテゴリ：VALIDATION
  • コード：INVALID_PARAMS
  • よくある原因：パラメーター名または値が無効です。
  • 推奨される対処方法：パラメーター名または値を修正し、そのパラメーターで指定できるオプションを確認します。
  • 例：Invalid parameter: 'invalid_param'. Valid options: ['param1', 'param2']

FILE_EXPORT_ERROR

  • カテゴリ：EXECUTION
  • コード：FILE_EXPORT_ERROR
  • よくある原因：データをファイルにエクスポートできませんでした。
  • 対処方法：出力先のパスと書き込み権限を確認してから、エクスポートを再試行します。出力先に同名のファイルがある場合は、別の名前を指定するか、置き換えたい場合に限り上書きを有効にしてください。
  • 例：File export failed: Permission denied

一般的なエラー #

UNEXPECTED_ERROR

  • カテゴリ：INTERNAL
  • コード：UNEXPECTED_ERROR
  • よくある原因：予期しない内部エラーが発生しました。
  • 推奨される対処方法：サポート用チェックリストに沿って最小限の再現例を用意し、普段利用している製品の窓口を通じて送付します。一般公開のサポート窓口はまだ掲載されていません。
  • 例：Unexpected error: NullPointerException
