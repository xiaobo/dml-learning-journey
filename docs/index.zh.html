让不同报表共用一个指标公式

用 DML 定义净收入、毛利率等指标，月报和地区报表都可以引用。你可以查看生成的 SQL，也可以用同一份数据和现有报表核对结果。

阅读文档跟着示例学 DML

扣除退款后，两张报表怎么变？

月报按月份汇总，地区报表按地区汇总。两张报表都用模型里的净收入。改下面这一行，再运行原来的两条查询。

原来的公式
net_revenue: SUM({amount})
扣除退款
net_revenue: SUM({amount}) - SUM({refund})
报表月份或地区原来扣除退款后
月报一月10090
月报二月230200
地区报表东区250210
地区报表西区8080

两笔退款都来自东区：一月退了 10，二月退了 30。西区没有退款，仍是 80。

查看模型和两条查询 
dialect: duckdb
Sales:
  type: dataset
  table: orders
  dimension: [order_id]
  columns:
    order_id:
    report_month:
    region:
    amount:
    refund:
  measures:
    net_revenue: SUM({amount})

月报

SELECT report_month, AGG(net_revenue) FROM MODEL GROUP BY report_month ORDER BY report_month DESC

地区报表

SELECT region, AGG(net_revenue) FROM MODEL GROUP BY region ORDER BY region
