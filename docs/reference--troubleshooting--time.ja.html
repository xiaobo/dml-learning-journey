ここでは、期間の値、比較コンテキスト、過去データの欠落を扱います。時間コンテキストの規則は評価セマンティクスで定義されています。

P29. 期間の初日以外を指定する時間フィルター #

誤り: dt_month = '2024-01-15' または dt_month = 'Jan 2024'。修正: dt_month = '2024-01-01'。必ず期間の初日を指定します。

P30. 直近 N 日間に今日が含まれない #

誤り: dt_date BETWEEN date(current_date, '-7 days') AND date(current_date, '-1 day')。修正: dt_date BETWEEN date(current_date, '-6 days') AND date(current_date)。今日を含む 7 日間になります。

P31. 直近 N か月に当月を含めている #

誤り: dt_month BETWEEN date(current_date, 'start of month', '-12 months') AND date(current_date, 'start of month')。修正: dt_month BETWEEN date(current_date, 'start of month', '-12 months') AND date(current_date, 'start of month', '-1 month')。まだ終了していない当月を除外します。

P32. 期間全体を単位とする GROUP BY で ytd 修飾子を使用している #

誤り: SELECT dt_year, AGG(sales, 'ytd') FROM MODEL GROUP BY dt_year。修正: ytd は累計値を返します。dt_date 単位で集計します。SELECT dt_date, AGG(sales, 'ytd') FROM MODEL WHERE dt_date = date(current_date) GROUP BY dt_date

P33. 期間の初日から基準日までの累計に日付範囲を指定している #

誤り: YTD に WHERE dt_date BETWEEN date(current_date, 'start of year') AND date(current_date) を使用する。修正: WHERE dt_date = date(current_date) と AGG(sales, 'ytd') を組み合わせます。日付範囲は修飾子が決定します。

カテゴリ：コンパイルと検証 #

P59. 比較対象の列を確認せずに前年同期比を求める #

誤り: 去年同期出厂价金额 の合計がゼロのときに AGG(销售额, 'yoy') を使用する。修正: 前年同期比について説明できると伝える前に、詳細クエリで SUM(去年同期出厂价金额) を確認します。

ソースデータの最終月より後の月が結果に含まれる #

期間を比較する場合は、レポートの対象月の範囲を明示的に指定します。完全外部結合では、どちらか一方の期間にだけ存在するグループも残ることがあります。12 月の売上が 1 月の前期売上として対応付けられると、日付範囲を制限していないクエリの結果には、レポートの対象外でも 1 月が含まれることがあります。

この例では、2024 年 1 月から 2025 年 12 月までのデータを使用します。毎月、5 つのカテゴリすべてに売上があります。モデルには、revenue: SUM({amount})、dt_month という名前の月ディメンション、revenue_mom: '{revenue: pop}' が定義されています。

SELECT dt_month, category, AGG(revenue), AGG(revenue_mom)
FROM MODEL
WHERE dt_month >= '2024-01-01' AND dt_month < '2026-01-01'
GROUP BY dt_month, category

サンプルデータでは、このクエリは 120 行を返し、手書きの SQL の結果と一致します。日付フィルターを外すと、検証対象のクエリは 125 行を返します。追加された 2026 年 1 月の 5 行には 12 月の売上だけが集計されるため、当期売上高と伸び率はいずれも NULL になります。

両期間の売上高をカテゴリ別に照合する #

期間ごとの売上高合計を比較するレポートでは、レポートの対象月の範囲内で、どちらかの期間に売上高があるカテゴリを残します。両方の値を表示するには、SELECT リストに AGG({revenue: pp}) AS previous_revenue を追加します。

カテゴリ 当期売上高 前期売上高
A 120 100
B NULL 40
C 30 NULL
合計 150 140

この例で当期に売上があるカテゴリだけに絞ると、B が除外され、表示される前期売上高の合計は 100 に減ります。当期に売上があるカテゴリを対象とするレポートにはこのフィルターを使用し、合計にも同じカテゴリの絞り込みを適用します。全体の比較を確認するには、売上高の各列をレポートの月ごとに合計し、それぞれ対応する月のソースデータの合計と照合します。全体の伸び率は、両期間の売上高合計から計算します。

対象期間のデータがそろっていて、売上がない場合を業務上ゼロとして扱うときに限り、欠損値をゼロとして表示します。ゼロで補完すると、表示値が変わります。
