运行并核对销售报表

本页目录

    下载 DuckDB 练习包

    解压后，在练习文件夹里运行下面两条命令。第一条把数据读入 DuckDB，第二条检查模型并运行报表。

    dmlc -q setup.sql
dmlc -q --with-validation --model=model.dml query.sql

    可选：用 PowerShell 自动核对结果。

    ./verify.ps1

    脚本在解压目录建立练习库，依次执行严格编译、独立校验和带校验的查询。三步退出码均为 0，verification.json 中的 result_matches 为 true 时，返回的两行六列与 expected.csv 一致。

    在 verification.json 中，version 记录运行时的 dmlc 版本，compiler_sha256 记录可执行文件的 SHA-256。再次运行时，请将练习解压到新的文件夹。

    本练习使用 互动教程 中的八条销售记录。需要使用自己的数据库时，参照 编译与校验步骤。
