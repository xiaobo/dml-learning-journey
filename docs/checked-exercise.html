运行并核对销售报表

本页目录

    下载 DuckDB 练习包，解压到一个新的可写目录。准备 Python、duckdb 和支持 --with-validation 的 dmlc.exe，然后在解压目录运行：

    py -m pip install duckdb==1.5.5
py verify.py C:/path/to/dmlc.exe

    脚本在解压目录建立练习库，依次执行严格编译、独立校验和带校验的查询。三步退出码均为 0，verification.json 中的 result_matches 为 true 时，返回的两行六列与 expected.csv 一致。

    包内记录对应 Windows amd64 的 dmlc 0.3.16（2026-11-27 02:57:23 Z）。脚本记录实际使用的构建和 SHA-256。再次运行时，请解压到新的目录。

    本练习使用 互动教程 中的八条销售记录。需要使用自己的数据库时，参照 编译与校验步骤。
