Eine Formel für mehrere Berichte

Definieren Sie Nettoumsatz oder Bruttomarge in DML. Monats- und Regionalberichte können dieselbe Formel verwenden. Sehen Sie sich das erzeugte SQL an oder führen Sie es mit denselben Daten wie Ihren bisherigen Bericht aus und vergleichen Sie die Ergebnisse.

Dokumentation lesenAn Beispielen lernen

Was ändert sich, wenn Sie Erstattungen abziehen?

Der Monatsbericht fasst Bestellungen nach Monat zusammen, der Regionalbericht nach Region. Beide verwenden den Nettoumsatz. Ändern Sie eine Zeile im Modell und führen Sie beide Abfragen erneut aus.

Bisherige Formel
net_revenue: SUM({amount})
Erstattungen abziehen
net_revenue: SUM({amount}) - SUM({refund})
BerichtMonat oder RegionVorherNach Abzug der Erstattungen
MonatsberichtJanuar10090
MonatsberichtFebruar230200
RegionalberichtOst250210
RegionalberichtWest8080

Beide Erstattungen betreffen die Region Ost: 10 im Januar und 30 im Februar. In der Region West gab es keine Erstattung. Der Nettoumsatz im Westen bleibt bei 80.

Modell und beide Abfragen ansehen 
dialect: duckdb
Sales:
  type: dataset
  table: orders
  dimension: [order_id]
  columns:
    order_id:
    report_month:
    region:
    amount:
    refund:
  measures:
    net_revenue: SUM({amount})

Monatsbericht

SELECT report_month, AGG(net_revenue) FROM MODEL GROUP BY report_month ORDER BY report_month DESC

Regionalbericht

SELECT region, AGG(net_revenue) FROM MODEL GROUP BY region ORDER BY region
