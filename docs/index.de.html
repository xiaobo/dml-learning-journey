Eine Formel für mehrere Berichte

Definieren Sie Nettoerlös oder Bruttomarge in DML. Monats- und Regionalberichte können dieselbe Formel verwenden. Sehen Sie sich das erzeugte SQL an oder führen Sie es mit denselben Daten wie Ihren bisherigen Bericht aus und vergleichen Sie die Ergebnisse.

Dokumentation lesenAn Beispielen lernen

Was ändert sich, wenn Sie Erstattungen abziehen?

Der Monatsbericht fasst Bestellungen nach Monat zusammen, der Regionalbericht nach Region. Beide verwenden den Nettoerlös. Ändern Sie eine Zeile im Modell und führen Sie beide Abfragen erneut aus.

Bisherige Formel
Nettoerlös: SUM({Bestellwert})
Erstattungen abziehen
Nettoerlös: SUM({Bestellwert}) - SUM({Erstattungsbetrag})
BerichtMonat oder RegionVorherNach Abzug der Erstattungen
MonatsberichtJanuar10090
MonatsberichtFebruar230200
RegionalberichtOst250210
RegionalberichtWest8080

Beide Erstattungen betreffen die Region Ost: 10 im Januar und 30 im Februar. In der Region West gab es keine Erstattung. Der Nettoerlös im Westen bleibt bei 80.

Modell und beide Abfragen ansehen 
dialect: duckdb
Bestellungen:
  type: dataset
  table: orders
  dimension: [Bestellnummer]
  columns:
    Bestellnummer:
      abbr: order_id
    dt_month:
      abbr: report_month
    Region:
      abbr: region
    Bestellwert:
      abbr: amount
    Erstattungsbetrag:
      abbr: refund
  measures:
    Nettoerlös: SUM({Bestellwert})

NettoerlösVormonat:
  type: measure
  formula: '{Nettoerlös: pp}'

Monatsbericht

SELECT dt_month, AGG(Nettoerlös) FROM MODEL GROUP BY dt_month ORDER BY dt_month

Regionalbericht

SELECT Region, AGG(Nettoerlös) FROM MODEL GROUP BY Region ORDER BY Region

Februar mit Januar vergleichen

Wählen Sie mit dt_month den Februar. Mit pp erhalten Sie für dieselbe Kennzahl den Nettoerlös des Vormonats. Nach Abzug der Erstattungen liegt der Nettoerlös im Februar bei 200 und im Januar bei 90.

SELECT AGG(Nettoerlös), AGG(NettoerlösVormonat) FROM MODEL WHERE dt_month='2025-02-01'
Ausführbare Beispiele herunterladen

Öffnen Sie im entpackten Projekt den Ordner net-revenue und führen Sie diese Befehle aus:

dmlc -q setup.sql
dmlc -q --model=model.dml monthly.sql
dmlc -q --model=model.dml regional.sql
dmlc -q --model=after-refunds/model.dml monthly.sql
dmlc -q --model=after-refunds/model.dml regional.sql
dmlc -q --model=after-refunds/model.dml previous-month.sql
