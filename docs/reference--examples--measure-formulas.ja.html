各式を使うには、式に出てくるデータセット、列、指標の定義が必要です。ここでは式の書き方を示します。テストとして実行するには、モデルとテストデータを用意してください。

業務で使う指標の例 #

財務指標 #

売掛金:
    type: measure
    formula: |-
        {売上金額: {+f: {勘定科目: 'Accounts Receivable (A/R)'}}}

未払額:
    type: measure
    description: All unpaid amounts (including not yet due)
    formula: |-
        {未決済残高}

支払期限到来残高:
    type: measure
    description: Amounts due today or earlier
    formula: |-
        {未決済残高: {+f: '支払期限 <= date(current_date)'}}

取引件数 #

請求書数:
    type: measure
    formula: |-
        {取引件数: {+f: {取引区分 : 'invoice'}}}

小切手数:
    type: measure
    formula: |-
        {取引件数: {+f: {取引区分 : 'check'}}}

受取小切手数:
    type: measure
    formula: |-
        {小切手数: {+f: '顧客 is not null'}}

名前の付け方、description:、abbrについてはモデルの確認を参照してください。よくある問題はトラブルシューティングの P1 と P25 で確認できます。

よく使う計算式 #

平均 #

平均請求額:
    type: measure
    formula: |-
        divide({売上金額: {+f: {取引区分: 'invoice'}}}, {請求書数})

頻度 #

一日当たり請求書数:
    type: measure
    formula: |-
        divide(sum({請求書数: {+d: dt_date}}), datediff(day, min({dt_date}), max({dt_date})) + 1)

年間売上高の平均 #

年平均収益:
    type: measure
    formula: |-
        divide(sum({収益: {+d: dt_year}}), distinctcount({dt_year}))
