Gemeinsames Modell für die Abfragebeispiele

Inhalt dieser Seite

    Die ersten Abfragebeispiele verwenden dieses Modell als model.dml. Bei späteren Beispielen sind weitere Abhängigkeiten angegeben. Prüfen Sie nach dem Kompilieren, ob die Quellschlüssel eindeutig sind und die Abfrage die erwarteten Ergebnisse liefert.

    # model.dml (shared)
Transaktionen:
    type: dataset
    table: fact_transactions
    dimension:
        - TransaktionsID
    columns:
        TransaktionsID:
            abbr: transaction_id
        dt_date:
            abbr: dt_date
        Produkt:
            abbr: product
        Region:
            abbr: region
        Kategorie:
            abbr: category
        Verkaufsbetrag:
            abbr: amount
        Anzahl:
            abbr: quantity
        Bezahlt:
            abbr: is_paid

Umsatz:
    type: measure
    dataset: Transaktionen
    formula: SUM({Verkaufsbetrag})
