Inhalt dieser Seite

    Vollständige, ausführbare Projekte finden Sie in den Aufgabenbeispielen. Jedes Projekt enthält Eingabedaten, ein Modell, Abfragen, erwartete Ausgaben und einen Eintrag zum erneuten Ausführen.

    Die folgenden Seiten enthalten nur Ausschnitte, sofern auf der jeweiligen Seite nichts anderes angegeben ist. Prüfen Sie ein vollständiges Modell und die zugehörige Abfrage mithilfe der Anleitung zur Kompilierung und Validierung.
