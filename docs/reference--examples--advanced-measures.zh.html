这些代码片段演示分布、生命周期、分群和累计排名。每种模式都需要其中指定的源指标和维度。这些片段不是验收测试用的固定样例。

加权铺货率（不同粒度指标相乘） #

加权铺货率衡量按门店重要程度加权后的品牌销售份额。计算时，需要将按不同粒度求得的指标值相乘，再向上汇总。

# Store-level sales (restricted to store + category grain)
门店品类销售额:
  type: measure
  formula: 'IIF({销售额} > 0, {销售额}, 0)'
  dimensions:
    - [dim_dt, 门店编号, 类别]

# Category-level sales (drop store)
品类销售额:
  type: measure
  formula: 'SUM({门店品类销售额: {+d: 门店编号}})'
  dimensions:
    - [dim_dt, 类别]

# Store weight = store sales / category sales (store + category grain)
门店权重:
  type: measure
  formula: 'DIVIDE({门店品类销售额}, {品类销售额: {-d: 门店编号}})'
  dimensions:
    - [dim_dt, 门店编号, 类别]

# Brand distribution flag (store + category + brand grain)
品牌铺货标记:
  type: measure
  formula: 'IIF({销售额} > 0, 1, 0)'
  dimensions:
    - [dim_dt, 门店编号, 类别, 品牌]

# Weighted distribution = SUM(store_weight * brand_flag) at brand grain
加权铺货率:
  type: measure
  formula: |-
    SUM({门店权重: {dimension: [dim_dt, 门店编号, 类别]}}
        * {品牌铺货标记: {dimension: [dim_dt, 门店编号, 类别, 品牌]}})
  dimensions:
    - [dim_dt, 类别, 品牌]

关键技巧：在 SUM() 内，dimension: 修饰符强制各组成指标按各自所需的粒度求值。编译器为每种粒度生成 CTE，并将它们连接起来。

跟踪产品生命周期 #

跟踪产品自首次售出以来的时长，按生命周期阶段对产品分类，并计算考虑新品销售历史较短的移动平均值。

# First sale date per product (restricted to product grain)
首次销售日期原值:
  type: measure
  formula: 'MINIF({dt_date}, {销售额: {+d: dt_date}} > 0)'

# First sale date, looking back up to 6 years
首次销售日期:
  type: measure
  formula: '{首次销售日期原值: p6y}'
  dimensions:
    - [dt_week, 商品]

# Weeks since launch
上市周数:
  type: measure
  formula: 'datediff(week, {首次销售日期}, {日历}.dt_week)'
  dimensions:
    - [dt_week, 商品]

# Flag: product has 2+ years of sales data
是否有两年数据:
  type: measure
  formula: 'IIF(MAX({上市周数: {+d: dt_week}}) > 104, 1, 0)'
  dimensions:
    - [商品]

# Total sales in first 2 years
前两年销售额:
  type: measure
  formula: |-
    SUMIF({销售额: {+d: dt_week}},
          {上市周数: {+d: dt_week}} >= 0
          AND {上市周数: {+d: dt_week}} < 104)
  dimensions:
    - [商品]

# Rolling 4-week average, adjusted for product age
近四周周均销售额:
  type: measure
  formula: |-
    DIVIDE({销售额: p4w},
           IIF({上市周数: {dimension: [商品, dt_week]}} >= 3,
               4,
               {上市周数: {dimension: [商品, dt_week]}} + 1))

关键技巧：

  • 将 MINIF 与 {+d: dt_date} 结合使用，可在 [dt_week, 商品] 的限定范围内按日粒度找出首次销售日期。
  • 自定义 dt-macro p6y 限制回溯时间范围（参见使用 +d 进行多级聚合中的“自定义宏定义”一节）。
  • 用 datediff 以 {日历}.dt_week 为基准计算时间差，根据日历数据集得出产品自首次售出以来的时长。
  • 将 SUMIF 与 {+d: dt_week} 结合使用，仅保留最初 104 周（2 年）内的各周。
  • 对于首次售出未满 4 周的产品，计算移动平均值时会调整分母。

使用 percent_rank 进行 RFM 分群 #

完整的 RFM 分群（距最近一次购买的时间、购买频率、购买金额），在指标公式中使用 percent_rank()，并基于 CASE 评分。

# Monetary: MAT sales (moving annual total)
消费金额:
  type: measure
  formula: '{销售额: mat}'
  dimensions:
    - [dim_dt, 客户编号]

# Recency: last purchase date
距上次购买天数:
  type: measure
  formula: 'MAXIF({dt_date}, {消费金额: {+d: dt_date}} > 0)'
  dimensions:
    - [dim_dt, 客户编号]

# Frequency: number of active sales days
购买次数:
  type: measure
  formula: 'DISTINCTCOUNTIF({dt_date}, {消费金额: {+d: dt_date}} > 0)'
  dimensions:
    - [dim_dt, 客户编号]

# Percentile ranks
最近购买天数百分位:
  type: measure
  formula: 'percent_rank() over (order by {距上次购买天数} desc)'
  dimensions:
    - [dim_dt, 客户编号]

购买次数百分位:
  type: measure
  formula: 'percent_rank() over (order by {购买次数} asc)'
  dimensions:
    - [dim_dt, 客户编号]

消费金额百分位:
  type: measure
  formula: 'percent_rank() over (order by {消费金额} asc)'
  dimensions:
    - [dim_dt, 客户编号]

# Scores (1-5 scale)
最近购买得分:
  type: measure
  formula: |-
    CASE
      WHEN {最近购买天数百分位} >= 0.8 THEN 5
      WHEN {最近购买天数百分位} >= 0.6 THEN 4
      WHEN {最近购买天数百分位} >= 0.4 THEN 3
      WHEN {最近购买天数百分位} >= 0.2 THEN 2
      ELSE 1
    END
  dimensions:
    - [dim_dt, 客户编号]

# (frequency_score and monetary_score follow the same pattern)

# Segment classification
客户分群:
  type: measure
  formula: |-
    CASE
      WHEN {最近购买得分} <= 2 AND {购买频率得分} <= 2 THEN 'Hibernating'
      WHEN {最近购买得分} <= 2 AND {购买频率得分} <= 4 THEN 'At Risk'
      WHEN {最近购买得分} <= 2 AND {购买频率得分} <= 5 THEN 'Cannot Lose Them'
      WHEN {最近购买得分} <= 3 AND {购买频率得分} <= 2 THEN 'About to Sleep'
      WHEN {最近购买得分} <= 3 AND {购买频率得分} <= 3 THEN 'Need Attention'
      WHEN {最近购买得分} <= 4 AND {购买频率得分} <= 1 THEN 'Promising'
      WHEN {最近购买得分} <= 4 AND {购买频率得分} <= 3 THEN 'Potential Loyalists'
      WHEN {最近购买得分} <= 4 AND {购买频率得分} <= 5 THEN 'Loyal Customers'
      WHEN {最近购买得分} <= 5 AND {购买频率得分} <= 1 THEN 'New Customers'
      WHEN {最近购买得分} <= 5 AND {购买频率得分} <= 3 THEN 'Potential Loyalists'
      ELSE 'Champions'
    END
  dimensions:
    - [dim_dt, 客户编号]

关键技巧：

  • 可在指标公式中使用 percent_rank() over (...)。.dml 公式支持窗口函数。
  • 所有 RFM 指标均限定在 [dim_dt, 客户编号] 粒度。系统变量 dim_dt 使这些指标可在任意时间粒度下计算。
  • 将 MAXIF 和 DISTINCTCOUNTIF 与 {+d: dt_date} 结合使用，计算距最近一次购买的时间和购买频率。
  • 使用 CASE 表达式组合各项评分，并据此将客户归入有明确名称的分群。

基于累计分布的产品排名 #

使用窗口函数计算累计和，将产品划分为不同层级（前 50%、前 80%、前 95%）。

# Product rank by total first-2-year sales
商品表现排名:
  type: measure
  formula: 'rank() over (order by {前两年销售额} desc)'
  dimensions:
    - [商品]

# Tier classification via cumulative distribution
商品分级:
  type: measure
  formula: |-
    CASE
      WHEN SUM({前两年销售额}) over (order by {前两年销售额} desc)
           <= 0.50 * SUM({前两年销售额}) over () THEN 'Top 50%'
      WHEN SUM({前两年销售额}) over (order by {前两年销售额} desc)
           <= 0.80 * SUM({前两年销售额}) over () THEN 'Top 80%'
      WHEN SUM({前两年销售额}) over (order by {前两年销售额} desc)
           <= 0.95 * SUM({前两年销售额}) over () THEN 'Top 95%'
      ELSE 'Others'
    END
  dimensions:
    - [商品]

关键技巧：SUM() over (order by ... desc) 计算累计和，SUM() over () 计算总和。累计和与总和的比值得出累计分布，用于帕累托式分类。所有计算均限定在 [商品] 粒度。
