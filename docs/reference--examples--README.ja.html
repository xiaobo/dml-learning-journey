タスク別の例

このページの内容

    そのまま実行できる完全なプロジェクトについては、タスク別の例を開いてください。各プロジェクトには、入力データ、モデル、クエリ、期待される出力、再実行用のエントリが含まれます。

    以下のページで紹介するパターンは、各ページに特に記載がない限り、断片的な例です。完全なモデルとクエリを確認するには、コンパイルと検証のガイドを参照してください。

    共通の売上モデル ソースモデル
    合計、期間比較、順位付け、フィルター クエリの例
    グループ化、補完、マテリアライズ、複数のデータセット モデルの例
    中間の集計レベルと、より細かいレベルで評価する述語 集計の例
    業務で使う計算式 指標の計算式の例
    分布、ライフサイクル、セグメント化 高度な指標
