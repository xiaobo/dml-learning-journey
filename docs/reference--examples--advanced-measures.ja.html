高度な指標の例

このページの内容
  • 加重配荷率（異なる粒度の指標の積）
  • 製品ライフサイクルの追跡
  • percent_rank を使った RFM セグメンテーション
  • 累積分布による製品ランキング

これらのコード断片は、分布、ライフサイクル、セグメンテーション、累積値による順位付けの例です。各パターンには、そこで指定された元の指標とディメンションが必要です。これらは受け入れテスト用のフィクスチャではありません。

加重配荷率（異なる粒度の指標の積） #

加重配荷率は、店舗の重要度で重み付けしたブランドの売上シェアを測定します。異なる粒度で評価した指標を掛け合わせ、その結果を上位の粒度に集計する必要があります。

# Store-level sales (restricted to store + category grain)
店舗別分類売上高:
  type: measure
  formula: 'IIF({売上高} > 0, {売上高}, 0)'
  dimensions:
    - [dim_dt, 店舗番号, 分類]

# Category-level sales (drop store)
分類別売上高:
  type: measure
  formula: 'SUM({店舗別分類売上高: {+d: 店舗番号}})'
  dimensions:
    - [dim_dt, 分類]

# Store weight = store sales / category sales (store + category grain)
店舗ウェイト:
  type: measure
  formula: 'DIVIDE({店舗別分類売上高}, {分類別売上高: {-d: 店舗番号}})'
  dimensions:
    - [dim_dt, 店舗番号, 分類]

# Brand distribution flag (store + category + brand grain)
ブランド取扱フラグ:
  type: measure
  formula: 'IIF({売上高} > 0, 1, 0)'
  dimensions:
    - [dim_dt, 店舗番号, 分類, ブランド]

# Weighted distribution = SUM(store_weight * brand_flag) at brand grain
加重配荷率:
  type: measure
  formula: |-
    SUM({店舗ウェイト: {dimension: [dim_dt, 店舗番号, 分類]}}
        * {ブランド取扱フラグ: {dimension: [dim_dt, 店舗番号, 分類, ブランド]}})
  dimensions:
    - [dim_dt, 分類, ブランド]

主な手法：dimension: 修飾子を使うと、SUM() の中で各構成指標がそれぞれ必要な粒度で評価されます。コンパイラは粒度ごとに CTE を生成し、それらを結合します。

製品ライフサイクルの追跡 #

初回販売からの経過期間を追跡し、製品をライフサイクルの段階別に分類して、新製品の販売期間の短さを考慮した移動平均を計算します。

# First sale date per product (restricted to product grain)
初回販売日元値:
  type: measure
  formula: 'MINIF({dt_date}, {売上高: {+d: dt_date}} > 0)'

# First sale date, looking back up to 6 years
初回販売日:
  type: measure
  formula: '{初回販売日元値: p6y}'
  dimensions:
    - [dt_week, 商品]

# Weeks since launch
発売後週数:
  type: measure
  formula: 'datediff(week, {初回販売日}, {カレンダー}.dt_week)'
  dimensions:
    - [dt_week, 商品]

# Flag: product has 2+ years of sales data
二年分データ有無:
  type: measure
  formula: 'IIF(MAX({発売後週数: {+d: dt_week}}) > 104, 1, 0)'
  dimensions:
    - [商品]

# Total sales in first 2 years
最初の二年間の売上高:
  type: measure
  formula: |-
    SUMIF({売上高: {+d: dt_week}},
          {発売後週数: {+d: dt_week}} >= 0
          AND {発売後週数: {+d: dt_week}} < 104)
  dimensions:
    - [商品]

# Rolling 4-week average, adjusted for product age
直近四週平均売上高:
  type: measure
  formula: |-
    DIVIDE({売上高: p4w},
           IIF({発売後週数: {dimension: [商品, dt_week]}} >= 3,
               4,
               {発売後週数: {dimension: [商品, dt_week]}} + 1))

主な手法：

  • MINIF に {+d: dt_date} を指定すると、[dt_week, 商品] に限定したうえで、日単位で初回販売日を求められます。
  • カスタム dt-macro p6y で、さかのぼる期間を制限します（+d を使った多段階集計の「カスタムマクロの定義」を参照）。
  • datediff で {カレンダー}.dt_week を基準に差を取り、カレンダーデータセットを使って初回販売からの経過期間を計算します。
  • SUMIF に {+d: dt_week} を指定すると、対象が最初の 104 週間（2 年間）に含まれる週に絞られます。
  • 初回販売から 4 週間未満の製品については、移動平均の分母を調整します。

percent_rank を使った RFM セグメンテーション #

RFM（最終購入からの経過期間、購入頻度、購入金額）のセグメンテーション全体を実装します。指標の式には percent_rank() を使い、CASE でスコアを付けます。

# Monetary: MAT sales (moving annual total)
購入金額:
  type: measure
  formula: '{売上高: mat}'
  dimensions:
    - [dim_dt, 顧客番号]

# Recency: last purchase date
最終購入からの日数:
  type: measure
  formula: 'MAXIF({dt_date}, {購入金額: {+d: dt_date}} > 0)'
  dimensions:
    - [dim_dt, 顧客番号]

# Frequency: number of active sales days
購入回数:
  type: measure
  formula: 'DISTINCTCOUNTIF({dt_date}, {購入金額: {+d: dt_date}} > 0)'
  dimensions:
    - [dim_dt, 顧客番号]

# Percentile ranks
購入経過日数百分位:
  type: measure
  formula: 'percent_rank() over (order by {最終購入からの日数} desc)'
  dimensions:
    - [dim_dt, 顧客番号]

購入回数百分位:
  type: measure
  formula: 'percent_rank() over (order by {購入回数} asc)'
  dimensions:
    - [dim_dt, 顧客番号]

購入金額百分位:
  type: measure
  formula: 'percent_rank() over (order by {購入金額} asc)'
  dimensions:
    - [dim_dt, 顧客番号]

# Scores (1-5 scale)
購入経過日数スコア:
  type: measure
  formula: |-
    CASE
      WHEN {購入経過日数百分位} >= 0.8 THEN 5
      WHEN {購入経過日数百分位} >= 0.6 THEN 4
      WHEN {購入経過日数百分位} >= 0.4 THEN 3
      WHEN {購入経過日数百分位} >= 0.2 THEN 2
      ELSE 1
    END
  dimensions:
    - [dim_dt, 顧客番号]

# (frequency_score and monetary_score follow the same pattern)

# Segment classification
顧客セグメント:
  type: measure
  formula: |-
    CASE
      WHEN {購入経過日数スコア} <= 2 AND {購入頻度スコア} <= 2 THEN 'Hibernating'
      WHEN {購入経過日数スコア} <= 2 AND {購入頻度スコア} <= 4 THEN 'At Risk'
      WHEN {購入経過日数スコア} <= 2 AND {購入頻度スコア} <= 5 THEN 'Cannot Lose Them'
      WHEN {購入経過日数スコア} <= 3 AND {購入頻度スコア} <= 2 THEN 'About to Sleep'
      WHEN {購入経過日数スコア} <= 3 AND {購入頻度スコア} <= 3 THEN 'Need Attention'
      WHEN {購入経過日数スコア} <= 4 AND {購入頻度スコア} <= 1 THEN 'Promising'
      WHEN {購入経過日数スコア} <= 4 AND {購入頻度スコア} <= 3 THEN 'Potential Loyalists'
      WHEN {購入経過日数スコア} <= 4 AND {購入頻度スコア} <= 5 THEN 'Loyal Customers'
      WHEN {購入経過日数スコア} <= 5 AND {購入頻度スコア} <= 1 THEN 'New Customers'
      WHEN {購入経過日数スコア} <= 5 AND {購入頻度スコア} <= 3 THEN 'Potential Loyalists'
      ELSE 'Champions'
    END
  dimensions:
    - [dim_dt, 顧客番号]

主な手法：

  • 指標の式の中で percent_rank() over (...) を使用できます。.dml の式ではウィンドウ関数が使えます。
  • すべての RFM 指標は [dim_dt, 顧客番号] の粒度に限定されます。システム変数 dim_dt により、任意の時間粒度で計算できます。
  • MAXIF と DISTINCTCOUNTIF に {+d: dt_date} を指定して、最終購入からの経過期間と購入頻度を計算します。
  • CASE 式でスコアを組み合わせ、名前の付いたセグメントに分類します。

累積分布による製品ランキング #

ウィンドウ関数で累積和を求め、製品をランク別に分類します（上位 50%、上位 80%、上位 95%）。

# Product rank by total first-2-year sales
商品実績順位:
  type: measure
  formula: 'rank() over (order by {最初の二年間の売上高} desc)'
  dimensions:
    - [商品]

# Tier classification via cumulative distribution
商品ランク:
  type: measure
  formula: |-
    CASE
      WHEN SUM({最初の二年間の売上高}) over (order by {最初の二年間の売上高} desc)
           <= 0.50 * SUM({最初の二年間の売上高}) over () THEN 'Top 50%'
      WHEN SUM({最初の二年間の売上高}) over (order by {最初の二年間の売上高} desc)
           <= 0.80 * SUM({最初の二年間の売上高}) over () THEN 'Top 80%'
      WHEN SUM({最初の二年間の売上高}) over (order by {最初の二年間の売上高} desc)
           <= 0.95 * SUM({最初の二年間の売上高}) over () THEN 'Top 95%'
      ELSE 'Others'
    END
  dimensions:
    - [商品]

主な手法：SUM() over (order by ... desc) で累積和を、SUM() over () で全体の合計を求めます。累積和を全体の合計で割ると、パレート方式の分類に使う累積分布が得られます。すべての計算は [商品] の粒度に限定されます。
