入门示例使用共享销售模型。该模型提供 sales 和列出的交易列，但不会创建源数据。日期示例使用当前日期，因此使用历史测试数据时可能不会返回任何行。

示例的前提条件：基本查询、销售额的期间比较、排名、占比和产品计数均使用该模型。费用示例还需要指标 expense。未结余额示例需要 customer 和 outstanding，账户增长示例需要 account 和 revenue。这些是需要按实际情况调整的片段，不能直接作为共享模型的扩展运行。如需可运行的数据集以及固定日期和预期结果，请使用经过验证的销售练习。

基本查询 #

销售总额 #

SELECT AGG(sales) FROM MODEL

按地区统计销售额 #

SELECT region, AGG(sales) FROM MODEL GROUP BY region

本月销售额 #

SELECT AGG(sales) FROM MODEL WHERE dt_month = date(current_date, 'start of month')

按地区统计本月销售额 #

SELECT region, AGG(sales)
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY region

明细查询：已付款交易 #

SELECT dt_date, transaction_id, amount, is_paid
FROM MODEL.transactions
WHERE is_paid = 1
ORDER BY dt_date DESC

时间修饰符 #

本月与上月对比 #

SELECT dt_month,
       AGG(sales) as this_month,
       AGG(sales, 'pp') as last_month,
       AGG(sales, 'pop') as mom_rate
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY dt_month

本月与去年同月对比 #

SELECT dt_month,
       AGG(sales) as this_month,
       AGG(sales, 'ya') as last_year_month,
       AGG(sales, 'yoy') as yoy_rate
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY dt_month

年初至今的增长率 #

SELECT dt_date,
       AGG(sales, 'ytd') as ytd_sales,
       AGG(sales, 'ytd', 'ya') as ytd_last_year,
       AGG(sales, 'ytd', 'yoy') as ytd_growth
FROM MODEL
WHERE dt_date = date(current_date)
GROUP BY dt_date

请注意修饰符的叠加：'ytd', 'ya' 表示从去年年初到去年同一日期的期间。

滚动 12 个月合计 #

SELECT dt_month, AGG(sales), AGG({sales: mat}) AS rolling_sales
FROM MODEL
GROUP BY dt_month
ORDER BY dt_month DESC
LIMIT 12

指定月份或季度 #

-- August this year
SELECT AGG(expense) FROM MODEL WHERE dt_month = date(current_date, 'start of year', '+7 months')

-- Q2 this year
SELECT AGG(expense) FROM MODEL WHERE dt_quarter = date(current_date, 'start of year', '+1 quarter')

.dml 中的嵌套修饰符 #

# In model.dml
sales_ytd:
    type: measure
    formula: '{sales: ytd}'

sales_ytd_last_year:
    type: measure
    formula: '{sales: {ytd: ya}}'

-- In query
SELECT dt_date, AGG(sales_ytd), AGG(sales_ytd_last_year)
FROM MODEL
WHERE dt_date = date(current_date)
GROUP BY dt_date

要点：时间修饰符需要明确的时间上下文，并且必须满足宏的前提条件。时间筛选条件也可以提供时间上下文。yoy 和 pop 返回以小数表示的增长率（0.15 = 15%）。pp 和 ya 返回前一比较期间的指标值本身。优先使用修饰符，避免手动计算日期。

排名与筛选 #

销售额排名前 10 的产品 #

SELECT product, AGG(sales)
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY product
ORDER BY AGG(sales) DESC
LIMIT 10

使用排名修饰符 #

SELECT product, AGG(sales), AGG({sales: rank}) AS sales_rank
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY product

{sales: rank} 返回各产品在查询结果中的销售额排名，按销售额降序排名。

选定期间内的排名 #

SELECT product,
       AGG(sales) as period_sales,
       AGG({sales: rank}) as selected_period_rank
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY product

查询已仅按产品分组。保留月份筛选条件，直接按 sales 排名即可，无需移除时间分组层级。移除分组字段与移除时间筛选条件是两种不同的操作。

按排名筛选 #

SELECT product, AGG(sales)
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY product
HAVING AGG({sales: rank}) <= 10

HAVING 在聚合后执行筛选，因此可以在该子句中使用 rank。

HAVING 子句：有未结余额的客户 #

SELECT customer, AGG(outstanding)
FROM MODEL
GROUP BY customer
HAVING AGG(outstanding) > 0

要点：rank 返回 RANK() OVER (ORDER BY measure DESC)。rank_asc 按值的升序返回排名。使用 -d 在排名之前移除时间维度或其他维度。将排名修饰符与 HAVING 结合使用，可动态筛选排名前 N 的结果。

占总计的比例（pot） #

SELECT product, AGG(sales) AS sales,
       AGG(sales, 'rank') AS sales_rank,
       AGG({sales: pot}) AS share_of_total
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY product
ORDER BY AGG(sales, 'rank')

pot 等于 measure / grand。帕累托分析中的累计占比不是系统 fn 宏。如需计算累计总和，请在 Model Query SQL 中使用 OVER()。

RFM 与共现模式 #

有关 RFM 分析和共现分析，请参阅含具体步骤的细粒度聚合示例。

不含 dt 的维度 #

按地区统计销售额（全部期间） #

SELECT region, AGG(sales) FROM MODEL GROUP BY region

按地区统计产品占比（不按时间分组） #

SELECT region, product, AGG(sales)
FROM MODEL
GROUP BY region, product

选定期间与全部历史期间对比 #

-- Selected month: retain the month filter.
SELECT region, product, AGG(sales) AS selected_period_sales
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY region, product

-- All history: remove the month filter, retain the same grouping.
SELECT region, product, AGG(sales) AS all_time_sales
FROM MODEL
GROUP BY region, product

请将这些查询分别运行。-d 移除分组，但保留时间筛选条件。这些查询不按时间分组，因此不需要 -d: dim_dt。如果在此处对单个指标应用移除时间分组层级的操作，用于验证的编译器会拒绝编译。若要仅针对分母移除分组和筛选条件，请参阅维度和筛选修饰符。

期间转换 #

SELECT dt_year,
       AGG({sales: {dim_dt as quarter: pp}}) as last_quarter_at_quarter_grain
FROM MODEL
WHERE dt_year = '2024-01-01'
GROUP BY dt_year

dim_dt as quarter 表示即使查询按年分组，pp 修饰符也按季度计算。系统先在转换后的层级（季度）计算指标，再将结果联接回查询层级（年）。

注意：只有转换后的时间层级与查询的时间分组层级不同时，dim_dt as <grain> 才有用。如果查询已按 dt_quarter 分组，编译器会拒绝多余的 dim_dt as quarter: pp。此时请直接使用 AGG({sales: pp})。

要点：没有时间筛选条件的查询会分析全部历史数据。-d: dim_dt 会从指标的计算维度中移除当前生效的时间字段。要指定当前生效的时间字段，请使用 dim_dt，不要指定 dt_date 之类的具体字段。-d 只能移除当前查询分组中包含的维度字段。dim_dt as <grain> 会更改单个指标引用的时间计算层级。混用时请注意，同一行中不按时间分组的指标与按时间分组的指标可能无法直接比较。

比较模式 #

与上一期间对比 #

SELECT AGG(sales) as this_month, AGG(sales, 'pp') as last_month
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')

按账户统计增长率 #

SELECT account, AGG(revenue) as current, AGG(revenue, 'pp') as previous
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY account
HAVING AGG(revenue, 'pop') > 0.10  -- 10% growth

年初至今与去年对比 #

SELECT AGG(sales, 'ytd') as this_ytd, AGG(sales, 'ytd', 'ya') as last_ytd
FROM MODEL
WHERE dt_date = date(current_date)
GROUP BY dt_date

条件计数 #

修饰符适用于指标，不适用于列。请在条件表达式中对指标使用 {+d: product}：

-- Count of products with per-product sales above threshold
SELECT DISTINCTCOUNTIF(product, AGG({sales: {+d: product}}) > 1000) as prod_cnt FROM MODEL

也可以在 .dml 中用 formula: 'DISTINCTCOUNTIF({product}, {sales: {+d: product}} > 1000)' 定义一次，再用 SELECT AGG(high_sales_product_count) FROM MODEL 查询。
