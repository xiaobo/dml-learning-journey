入门示例使用共享销售模型。该模型提供 销售额 和列出的交易列，但不会创建源数据。日期示例使用当前日期，因此使用历史测试数据时可能不会返回任何行。

示例的前提条件：基本查询、销售额的期间比较、排名、占比和产品计数均使用该模型。费用示例还需要指标 费用。未结余额示例需要 客户 和 未付金额，账户增长示例需要 账户 和 收入。这些是需要按实际情况调整的片段，不能直接作为共享模型的扩展运行。如需可运行的数据集以及固定日期和预期结果，请使用经过验证的销售练习。

基本查询 #

销售总额 #

SELECT AGG(销售额) FROM MODEL

按地区统计销售额 #

SELECT 地区, AGG(销售额) FROM MODEL GROUP BY 地区

本月销售额 #

SELECT AGG(销售额) FROM MODEL WHERE dt_month = date(current_date, 'start of month')

按地区统计本月销售额 #

SELECT 地区, AGG(销售额)
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 地区

明细查询：已付款交易 #

SELECT dt_date, 交易编号, 销售金额, 是否已付款
FROM MODEL.交易明细
WHERE 是否已付款 = 1
ORDER BY dt_date DESC

时间修饰符 #

本月与上月对比 #

SELECT dt_month,
       AGG(销售额) as 本月销售额,
       AGG(销售额, 'pp') as 上月销售额,
       AGG(销售额, 'pop') as 环比增长率
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY dt_month

本月与去年同月对比 #

SELECT dt_month,
       AGG(销售额) as 本月销售额,
       AGG(销售额, 'ya') as 上年同月销售额,
       AGG(销售额, 'yoy') as 同比增长率
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY dt_month

年初至今的增长率 #

SELECT dt_date,
       AGG(销售额, 'ytd') as 本年累计销售额,
       AGG(销售额, 'ytd', 'ya') as 上年同期累计销售额,
       AGG(销售额, 'ytd', 'yoy') as 累计销售额同比增幅
FROM MODEL
WHERE dt_date = date(current_date)
GROUP BY dt_date

请注意修饰符的叠加：'ytd', 'ya' 表示从去年年初到去年同一日期的期间。

滚动 12 个月合计 #

SELECT dt_month, AGG(销售额), AGG({销售额: mat}) AS 滚动销售额
FROM MODEL
GROUP BY dt_month
ORDER BY dt_month DESC
LIMIT 12

指定月份或季度 #

-- August this year
SELECT AGG(费用) FROM MODEL WHERE dt_month = date(current_date, 'start of year', '+7 months')

-- Q2 this year
SELECT AGG(费用) FROM MODEL WHERE dt_quarter = date(current_date, 'start of year', '+1 quarter')

.dml 中的嵌套修饰符 #

# In model.dml
本年累计销售额:
    type: measure
    formula: '{销售额: ytd}'

上年同期累计销售额:
    type: measure
    formula: '{销售额: {ytd: ya}}'

-- In query
SELECT dt_date, AGG(本年累计销售额), AGG(上年同期累计销售额)
FROM MODEL
WHERE dt_date = date(current_date)
GROUP BY dt_date

要点：时间修饰符需要明确的时间上下文，并且必须满足宏的前提条件。时间筛选条件也可以提供时间上下文。yoy 和 pop 返回以小数表示的增长率（0.15 = 15%）。pp 和 ya 返回前一比较期间的指标值本身。优先使用修饰符，避免手动计算日期。

排名与筛选 #

销售额排名前 10 的产品 #

SELECT 商品, AGG(销售额)
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品
ORDER BY AGG(销售额) DESC
LIMIT 10

使用排名修饰符 #

SELECT 商品, AGG(销售额), AGG({销售额: rank}) AS 销售排名
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品

{销售额: rank} 返回各产品在查询结果中的销售额排名，按销售额降序排名。

选定期间内的排名 #

SELECT 商品,
       AGG(销售额) as 期间销售额,
       AGG({销售额: rank}) as 所选期间排名
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品

查询已仅按产品分组。保留月份筛选条件，直接按 销售额 排名即可，无需移除时间分组层级。移除分组字段与移除时间筛选条件是两种不同的操作。

按排名筛选 #

SELECT 商品, AGG(销售额)
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品
HAVING AGG({销售额: rank}) <= 10

HAVING 在聚合后执行筛选，因此可以在该子句中使用 rank。

HAVING 子句：有未结余额的客户 #

SELECT 客户, AGG(未付金额)
FROM MODEL
GROUP BY 客户
HAVING AGG(未付金额) > 0

要点：rank 返回 RANK() OVER (ORDER BY measure DESC)。rank_asc 按值的升序返回排名。使用 -d 在排名之前移除时间维度或其他维度。将排名修饰符与 HAVING 结合使用，可动态筛选排名前 N 的结果。

占总计的比例（pot） #

SELECT 商品, AGG(销售额) AS 销售额,
       AGG(销售额, 'rank') AS 销售排名,
       AGG({销售额: pot}) AS 占总额的比例
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品
ORDER BY AGG(销售额, 'rank')

pot 等于 measure / grand。帕累托分析中的累计占比不是系统 fn 宏。如需计算累计总和，请在 Model Query SQL 中使用 OVER()。

RFM 与共现模式 #

有关 RFM 分析和共现分析，请参阅含具体步骤的细粒度聚合示例。

不含 dt 的维度 #

按地区统计销售额（全部期间） #

SELECT 地区, AGG(销售额) FROM MODEL GROUP BY 地区

按地区统计产品占比（不按时间分组） #

SELECT 地区, 商品, AGG(销售额)
FROM MODEL
GROUP BY 地区, 商品

选定期间与全部历史期间对比 #

-- Selected month: retain the month filter.
SELECT 地区, 商品, AGG(销售额) AS 所选期间销售额
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 地区, 商品

-- All history: remove the month filter, retain the same grouping.
SELECT 地区, 商品, AGG(销售额) AS 历年销售额
FROM MODEL
GROUP BY 地区, 商品

请将这些查询分别运行。-d 移除分组，但保留时间筛选条件。这些查询不按时间分组，因此不需要 -d: dim_dt。如果在此处对单个指标应用移除时间分组层级的操作，用于验证的编译器会拒绝编译。若要仅针对分母移除分组和筛选条件，请参阅维度和筛选修饰符。

期间转换 #

SELECT dt_year,
       AGG({销售额: {dim_dt as quarter: pp}}) as 上季季度销售额
FROM MODEL
WHERE dt_year = '2024-01-01'
GROUP BY dt_year

dim_dt as quarter 表示即使查询按年分组，pp 修饰符也按季度计算。系统先在转换后的层级（季度）计算指标，再将结果联接回查询层级（年）。

注意：只有转换后的时间层级与查询的时间分组层级不同时，dim_dt as <grain> 才有用。如果查询已按 dt_quarter 分组，编译器会拒绝多余的 dim_dt as quarter: pp。此时请直接使用 AGG({销售额: pp})。

要点：没有时间筛选条件的查询会分析全部历史数据。-d: dim_dt 会从指标的计算维度中移除当前生效的时间字段。要指定当前生效的时间字段，请使用 dim_dt，不要指定 dt_date 之类的具体字段。-d 只能移除当前查询分组中包含的维度字段。dim_dt as <grain> 会更改单个指标引用的时间计算层级。混用时请注意，同一行中不按时间分组的指标与按时间分组的指标可能无法直接比较。

比较模式 #

与上一期间对比 #

SELECT AGG(销售额) as 本月销售额, AGG(销售额, 'pp') as 上月销售额
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')

按账户统计增长率 #

SELECT 账户, AGG(收入) as current, AGG(收入, 'pp') as previous
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 账户
HAVING AGG(收入, 'pop') > 0.10  -- 10% growth

年初至今与去年对比 #

SELECT AGG(销售额, 'ytd') as 本年累计, AGG(销售额, 'ytd', 'ya') as 上年同期累计
FROM MODEL
WHERE dt_date = date(current_date)
GROUP BY dt_date

条件计数 #

修饰符适用于指标，不适用于列。请在条件表达式中对指标使用 {+d: 商品}：

-- Count of products with per-商品 销售额 above threshold
SELECT DISTINCTCOUNTIF(商品, AGG({销售额: {+d: 商品}}) > 1000) as 商品数 FROM MODEL

也可以在 .dml 中用 formula: 'DISTINCTCOUNTIF({商品}, {销售额: {+d: 商品}} > 1000)' 定义一次，再用 SELECT AGG(high_sales_product_count) FROM MODEL 查询。
