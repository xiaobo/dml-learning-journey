集計順序を定めた売上累計の指標を再利用する

このページの内容
  • 定義と結果を確認する
  • ウィンドウ計算の前にフィルタリングすると累計の開始位置が変わる
  • 検証を実行して結果を確認する

集計順序を定めた累計を名前付きの指標として定義し、その指標を使用できる集計レベルを指定します。この例で累計するのは売上です。粗利益率や月ごとの重複を除いた顧客数は累計しません。

定義と結果を確認する #

月別売上は1月が40、2月が20です。累計売上額は、1月に40、2月に60を返します。

累計売上額:
  type: measure
  formula: 'SUM({売上額}) OVER (ORDER BY {dt_month} ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)'
  dimensions:
    - [dt_month]

ORDER BY dt_monthで月を時系列順に並べ、ROWSで先頭から現在の行まで合計します。パーティションを指定していないため、まず全地域の月別売上額を求めます。dimensions: [[dt_month]]で月単位の集計を指定します。元のテーブルでは月を日付として保存しています。

ファイル全体: fixed/model.dml 
dialect: duckdb
売上明細:
  type: dataset
  table: FACT
  dimension: [番号]
  columns:
    番号:
      abbr: id
    地域:
      abbr: region
    dt_month:
      abbr: month
    注文金額:
      abbr: amount
  measures:
    売上額: SUM({注文金額})
地域別選択月売上額:
  type: measure
  formula: '{売上額: {-d: dt_month}}'
地域別全月売上額:
  type: measure
  formula: '{売上額: {-df: dt_month}}'
累計売上額:
  type: measure
  formula: 'SUM({売上額}) OVER (ORDER BY {dt_month} ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)'
  dimensions:
    - [dt_month]
ファイル全体: fixed/running.sql 
SELECT dt_month, AGG(売上額), AGG(累計売上額) FROM MODEL GROUP BY dt_month ORDER BY dt_month

他のクエリからも同じ指標累計売上額を参照できます。地域ごとに売上を累計するには、パーティションと使用可能な集計レベルを定義し、その結果を確認します。クエリに地域を追加するだけでは、地域ごとの累計にはなりません。

ウィンドウ計算の前にフィルタリングすると累計の開始位置が変わる #

ファイル全体: fixed/running_february.sql 
SELECT dt_month, AGG(売上額), AGG(累計売上額) FROM MODEL WHERE dt_month='2024-02-01' GROUP BY dt_month ORDER BY dt_month

2月だけを選択すると、売上も売上累計も20になります。1月の40は自動では引き継がれません。累計の対象は、選択された結果の行です。年初から2月末までを累計するには、YTDで対象期間を明示し、計算に含まれる入力データを確認します。詳しくは累計KPIを参照してください。

指標値順の累積順位は、時系列順に計算した累計値ではありません。並び順は定義の一部です。{売上額: {dimension: []}}のように集計レベルを空にすると、順序に従った累計ではなく、全体の合計が求められます。

検証を実行して結果を確認する #

プロジェクトをダウンロードして、READMEの手順に従い、PowerShellでverify.ps1を実行します。dmlcにパスを通してください。新しい出力フォルダーに演習用データベースを作成し、結果と診断情報を保存します。

この例は DuckDB 上で dmlc 0.3.16（ビルド 2026-11-27）を使って確認しました。実行ファイルのフィンガープリントと各検証ケースのステータスは、ダウンロードに含まれる verification-summary.json に記載されています。データベースでの検証とその後の実行は独立した処理です。両方が同じスナップショットを使用する保証はありません。他のデータベースエンジンでは個別に確認してください。
