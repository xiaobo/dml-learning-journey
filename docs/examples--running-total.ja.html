集計順序を定めた売上累計の指標を再利用する

このページの内容
  • 定義と結果を確認する
  • ウィンドウ計算の前にフィルタリングすると累計の開始位置が変わる
  • 検証を実行して結果を確認する

集計順序を定めた累計を名前付きの指標として定義し、その指標を使用できる集計レベルを指定します。この例で累計するのは売上です。粗利益率や月ごとの重複を除いた顧客数は累計しません。

定義と結果を確認する #

月別売上は1月が40、2月が20です。running_salesは、1月に40、2月に60を返します。

running_sales:
  type: measure
  formula: 'SUM({sales}) OVER (ORDER BY {month} ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)'
  dimensions:
    - [month]

ORDER BY monthで時系列順を指定し、ROWSで最初の行から現在の行までを累計します。パーティションがないため、まず全地域の売上を月ごとに合算します。dimensions: [[month]]により、この指標を使用できる集計レベルは月に限定されます。ISO形式の月を表す文字列は、ソートすると時系列順に並びます。

ファイル全体: fixed/model.dml 
dialect: duckdb
F:
  type: dataset
  table: FACT
  dimension: [id]
  columns:
    id:
    region:
    month:
    amount:
  measures:
    sales: SUM({amount})
region_selected:
  type: measure
  formula: '{sales: {-d: month}}'
region_all_months:
  type: measure
  formula: '{sales: {-df: month}}'
running_sales:
  type: measure
  formula: 'SUM({sales}) OVER (ORDER BY {month} ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)'
  dimensions:
    - [month]
ファイル全体: fixed/running.sql 
SELECT month, AGG(sales), AGG(running_sales) FROM MODEL GROUP BY month ORDER BY month

他のクエリからも同じ指標running_salesを参照できます。地域ごとに売上を累計するには、パーティションと使用可能な集計レベルを定義し、その結果を確認します。クエリに地域を追加するだけでは、地域ごとの累計にはなりません。

ウィンドウ計算の前にフィルタリングすると累計の開始位置が変わる #

ファイル全体: fixed/running_february.sql 
SELECT month, AGG(sales), AGG(running_sales) FROM MODEL WHERE month='2024-02-01' GROUP BY month ORDER BY month

2月だけを選択すると、売上も売上累計も20になります。1月の40は自動では引き継がれません。累計の対象は、選択された結果の行です。年初から2月末までを累計するには、YTDで対象期間を明示し、計算に含まれる入力データを確認します。詳しくは累計KPIを参照してください。

指標値順の累積順位は、時系列順に計算した累計値ではありません。並び順は定義の一部です。{sales: {dimension: []}}のように集計レベルを空にすると、順序に従った累計ではなく、全体の合計が求められます。

検証を実行して結果を確認する #

プロジェクトをダウンロードして、READMEの手順に従い、PowerShellでverify.ps1を実行します。dmlcにパスを通してください。新しい出力フォルダーに演習用データベースを作成し、結果と診断情報を保存します。

この例は DuckDB 上で dmlc 0.3.16（ビルド 2026-11-13）を使って確認しました。実行ファイルのフィンガープリントと各検証ケースのステータスは、ダウンロードに含まれる verification-summary.json に記載されています。データベースでの検証とその後の実行は独立した処理です。両方が同じスナップショットを使用する保証はありません。他のデータベースエンジンでは個別に確認してください。
