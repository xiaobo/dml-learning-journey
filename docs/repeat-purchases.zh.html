同一天进两次货，算复购吗？

四家店，一周，六张进货单。A 店周一下了两单，B 店周一、周二各下一单。周报要统计复购门店，你会把 A 店算进去吗？

A 店算复购吗？

在原始六单里，按订单数算，A 店和 B 店都算复购。

在原始六单里，按采购日算，只有 B 店算复购。

本周门店复购率

本周四家店都进过货，所以两种算法都除以 4。每一行是一张进货单，件数都大于零。两种改动都从原始六单开始。

A 店的两张单都在周一。按店数，A 店是 2 单、1 天，B 店是 2 单、2 天。按天算，只有 B 店入选。

{+d: store_id} 让 DML 逐店判断。每家符合条件的店只计一次，再用入选门店数除以本周进过货的门店数。

迁移前，用这份账本核对

先约定周报要回答哪个问题，再让现有 SQL 和 DML 在同一份账本上各跑一次。先比入选的门店，再比比例。下载包包含六单数据、两种指标的 DML 定义、对照 SQL 和三种情况的核对脚本。

这三个场景的数字来自实际运行的 DML 查询，已用同一份数据和独立的 SQL 查询核对。

查看计算结果时用到的两条查询
SELECT store_id, AGG(order_count), AGG(purchase_days)
FROM repurchase
GROUP BY store_id
ORDER BY store_id
SELECT AGG(active_stores), AGG(repeat_by_order), AGG(repeat_by_day),
       AGG(repeat_purchase_rate_by_order_count), AGG(repeat_purchase_rate_by_purchase_days)
FROM repurchase

查看两种复购率的 DML 定义
dialect: duckdb

RECEIPTS:
  type: dataset
  table: receipts
  dimension: [order_id]
  columns:
    order_id:
    store_id:
    purchase_day:
    units:
  measures:
    order_count: DISTINCTCOUNT({order_id})
    purchase_days: DISTINCTCOUNT({purchase_day})
    purchased_units: SUM({units})

active_stores:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {purchased_units: {+d: store_id}} > 0)'

repeat_by_order:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {order_count: {+d: store_id}} > 1)'

repeat_by_day:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {purchase_days: {+d: store_id}} > 1)'

repeat_purchase_rate_by_order_count:
  type: measure
  formula: 'DIVIDE(1.0 * {repeat_by_order}, {active_stores})'

repeat_purchase_rate_by_purchase_days:
  type: measure
  formula: 'DIVIDE(1.0 * {repeat_by_day}, {active_stores})'
