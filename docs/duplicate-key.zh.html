duplicate_key
排查重复键

先看校验报告里列出的数据集和键。模型要求这个键唯一，但这次校验找到了重复记录。

找出重复记录

本例的地区表 DIM 用 id 和 region 一起标识一条记录。编号 1 可以在东区和西区各出现一次。用下面的 SQL 检查两个字段的组合。

SELECT id, region, COUNT(*) AS matches
FROM DIM
GROUP BY id, region
HAVING COUNT(*) > 1;
idregionmatches
1east2

这会怎样影响报表？

东区只有一笔 10 元的销售。地区表中有两条 (1, east)，用普通 SQL 关联时，这笔销售会匹配两次，合计变成 20 元。西区仍是 20 元。

修正后再核对

先确认两条记录是否本来就应当不同。如果两行都有效，检查模型声明的键是否完整。本例中第二条东区记录是误加的。修正地区表后，重新校验，再运行报表。东区应回到 10，西区仍是 20。
