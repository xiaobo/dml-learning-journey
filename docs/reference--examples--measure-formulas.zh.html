财务指标 #

应收账款:
    type: measure
    formula: |-
        {销售金额: {+f: {账户: 'Accounts Receivable (A/R)'}}}

未付金额:
    type: measure
    description: All unpaid amounts (including not yet due)
    formula: |-
        {未结余额}

到期应付余额:
    type: measure
    description: Amounts due today or earlier
    formula: |-
        {未结余额: {+f: '到期日期 <= date(current_date)'}}

交易笔数 #

发票数:
    type: measure
    formula: |-
        {交易笔数: {+f: {交易类型 : 'invoice'}}}

支票数:
    type: measure
    formula: |-
        {交易笔数: {+f: {交易类型 : 'check'}}}

收到的支票数:
    type: measure
    formula: |-
        {支票数: {+f: '客户 is not null'}}

命名、description: 和 abbr 的规则见检查模型。常见问题见排错目录中的 P1 和 P25。

常用公式 #

计算平均值 #

平均发票金额:
    type: measure
    formula: |-
        divide({销售金额: {+f: {交易类型: 'invoice'}}}, {发票数})

计算频率 #

日均开票数:
    type: measure
    formula: |-
        divide(sum({发票数: {+d: dt_date}}), datediff(day, min({dt_date}), max({dt_date})) + 1)

年均收入 #

年均收入:
    type: measure
    formula: |-
        divide(sum({收入: {+d: dt_year}}), distinctcount({dt_year}))
