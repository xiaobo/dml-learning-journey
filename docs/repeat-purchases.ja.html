同じ日に同じ仕入れ先に2回注文したら、リピート購入に数えますか？

今週は4店舗から注文がありました。A店は月曜日に2件、B店は月曜日と火曜日に1件ずつ注文しました。売上の週次レポートでは、どの店舗をリピート購入した店舗として数えますか？

今週の6件の注文

注文番号店舗注文日個数
1A店月曜日1
2A店月曜日1
3B店月曜日1
4B店火曜日1
5C店月曜日2
6D店火曜日2

1行が1件の注文です。どの注文も数量は1個以上です。

週次レポートで知りたいのはどちらですか？

最初の6件では、A店とB店がこの条件に当てはまります。

最初の6件で、この条件に当てはまるのはB店だけです。

それぞれの数え方で、どの店舗が当てはまりますか？

今週の注文だけを数えます。先週注文した店舗でも、今週の注文が1件だけなら、どちらの数え方でも今週のリピート購入には含めません。

注文を変えて、該当する店舗を見比べてみましょう。それぞれ最初の6件から試せます。

最初の6件

A店もB店も注文は2件です。A店は同じ日に2件、B店は別々の日に1件ずつ注文しました。

注文件数で数える

50%

今週注文した4店舗のうち、該当するのは2店舗（A店、B店）です。

今週2件以上注文した店舗が該当します。DMLでは異なる注文番号を数えます。

注文件数: DISTINCTCOUNT({注文番号})

A店には異なる注文番号が二つあるので該当します。 注文件数 = 2

店舗数とリピート購入率のDMLの式を見る

{+d: 店舗番号} を指定すると、店舗ごとに条件を判定します。条件を満たす店舗を1店ずつ数えます。 式では日本語の指標名を使い、abbr に英語名を指定しています。

注文件数で数えたリピート店舗数:
  type: measure
  abbr: repeat_purchase_by_orders
  formula: 'DISTINCTCOUNTIF({店舗番号}, {注文件数: {+d: 店舗番号}} > 1)'

条件を満たす2店舗を、今週注文した4店舗で割ると、リピート購入率は50%です。

注文件数で数えたリピート購入率:
  type: measure
  abbr: repeat_purchase_rate_by_orders
  formula: 'DIVIDE(1.0 * {注文件数で数えたリピート店舗数}, {注文店舗数})'

注文した日数で数える

今週注文した4店舗のうち、該当するのは1店舗（B店）です。

今週2日以上注文した店舗が該当します。同じ日に何件注文しても1日と数えます。

注文日数: DISTINCTCOUNT({dt_date})

A店が注文したのは1日だけなので該当しません。 注文日数 = 1

自社の週次レポートと照合する

週次レポートで使う条件を決め、同じ週の注文を対象に既存のSQLとDMLのクエリを実行します。先に店舗の一覧を照合し、次に割合を比べます。割合が同じでも、店舗の顔ぶれが違うことがあります。

6件の注文で試す

上の数値はDMLのクエリを実行した結果です。検証用スクリプトは同じ注文を使って別のSQLクエリを実行し、各店舗の注文件数と注文した日数を照合してから、二つの割合を確認します。

サンプルを実行する

展開先で注文をDuckDBに読み込み、店舗ごとの注文件数と注文した日数、二つのリピート購入率を確認します。

dmlc -q setup.sql
dmlc -q --with-validation --model=repurchase.dml stores.sql
dmlc -q --with-validation --model=repurchase.dml rates.sql

必要に応じて、PowerShellで結果を自動照合できます。

./verify.ps1

スクリプトは、最初の注文、A店の注文日を変えた場合、C店とD店の注文を分けた場合の順に確認します。

週次レポートに使う二つのクエリを見る

まず、各店舗の注文件数と注文した日数を調べます。

SELECT 店舗番号, AGG(注文件数), AGG(注文日数)
FROM repurchase
GROUP BY 店舗番号
ORDER BY 店舗番号

次に、リピート購入した店舗数とリピート購入率を確認します。

SELECT AGG(注文店舗数), AGG(注文件数で数えたリピート店舗数), AGG(注文日数で数えたリピート店舗数),
       AGG(注文件数で数えたリピート購入率), AGG(注文日数で数えたリピート購入率)
FROM repurchase
火曜日と月曜日の注文件数を比べる

dt_date に火曜日を指定すると、pp で前日の注文件数を取得できます。最初の6件では、火曜日は2件、月曜日は4件です。

SELECT AGG(注文件数), AGG(前日の注文件数)
FROM repurchase
WHERE dt_date = '2025-02-04'
dmlc -q --model=repurchase.dml previous-day.sql
