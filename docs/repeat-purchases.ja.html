同じ日に2回注文したら、リピート購入に数えますか？

ある週、4店舗から6件の仕入れ注文がありました。A店は月曜日に2回、B店は月曜日と火曜日に1回ずつ注文しています。週次レポートでは、A店をリピート購入した店舗に含めますか？

この週の6件の注文

注文番号店舗仕入れ日数量
1A月曜日1
2A月曜日1
3B月曜日1
4B火曜日1
5C月曜日2
6D火曜日2

A店をリピート購入した店舗として数えますか？

最初の6件では、注文件数で数えるとA店とB店が該当します。

最初の6件では、仕入れた日数で数えるとB店だけが該当します。

今週のリピート購入率

この週は4店舗とも仕入れたので、どちらの割合も4で割ります。1行が1件の注文で、どの注文も数量は1個以上です。二つの変更は、それぞれ元の6件に加えます。

元の6件

A店は月曜日に2件注文しました。A店は2件で1日、B店は2件で2日です。仕入れ日数で数えると、該当するのはB店だけです。

{+d: store_id} を指定すると、店舗ごとに条件を判定します。条件を満たす店舗を1店ずつ数え、その週に仕入れた店舗数で割ります。

移行前に結果を確かめる

まず、週次レポートに含める店舗の条件を決めます。同じ注文データで既存のSQLとDMLのクエリを実行し、該当する店舗を照合してから割合を比べます。ダウンロードには注文データ、二つのDML定義、照合用のSQL、3通りの結果を確認するスクリプトが含まれます。

ここに表示する数値は、三つのケースそれぞれでDMLのクエリを実行した結果です。同じ注文データを使い、別のSQLクエリで照合しました。

結果の確認に使った二つのクエリを見る
SELECT store_id, AGG(order_count), AGG(purchase_days)
FROM repurchase
GROUP BY store_id
ORDER BY store_id
SELECT AGG(active_stores), AGG(repeat_by_order), AGG(repeat_by_day),
       AGG(repeat_purchase_rate_by_order_count), AGG(repeat_purchase_rate_by_purchase_days)
FROM repurchase

注文データ、モデル、クエリをダウンロード (.zip)

ファイルを展開し、Python用のDuckDBパッケージが入った環境で実行します。DMLC_PATH は dmlc 実行ファイルのパスに置き換えてください。

python verify.py --dmlc "DMLC_PATH"

dialect: duckdb

RECEIPTS:
  type: dataset
  table: receipts
  dimension: [order_id]
  columns:
    order_id:
    store_id:
    purchase_day:
    units:
  measures:
    order_count: DISTINCTCOUNT({order_id})
    purchase_days: DISTINCTCOUNT({purchase_day})
    purchased_units: SUM({units})

active_stores:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {purchased_units: {+d: store_id}} > 0)'

repeat_by_order:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {order_count: {+d: store_id}} > 1)'

repeat_by_day:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {purchase_days: {+d: store_id}} > 1)'

repeat_purchase_rate_by_order_count:
  type: measure
  formula: 'DIVIDE(1.0 * {repeat_by_order}, {active_stores})'

repeat_purchase_rate_by_purchase_days:
  type: measure
  formula: 'DIVIDE(1.0 * {repeat_by_day}, {active_stores})'
