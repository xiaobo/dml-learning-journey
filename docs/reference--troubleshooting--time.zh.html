本节介绍期间值、比较上下文和历史数据缺失的问题。时间上下文的规则由求值语义定义。

P29. 时间筛选使用了非期间首日 #

错误：dt_month = '2024-01-15' 或 dt_month = 'Jan 2024'。修正：dt_month = '2024-01-01'。始终使用期间的第一天。

P30. 最近 N 天漏掉了今天 #

错误：dt_date BETWEEN date(current_date, '-7 days') AND date(current_date, '-1 day')。修正：dt_date BETWEEN date(current_date, '-6 days') AND date(current_date)。范围共 7 天，包含今天。

P31. 最近 N 个月包含了当月 #

错误：dt_month BETWEEN date(current_date, 'start of month', '-12 months') AND date(current_date, 'start of month')。修正：dt_month BETWEEN date(current_date, 'start of month', '-12 months') AND date(current_date, 'start of month', '-1 month')。排除尚未结束的当月。

P32. 在按完整期间执行 GROUP BY 时使用 ytd 修饰符 #

错误：SELECT dt_year, AGG(sales, 'ytd') FROM MODEL GROUP BY dt_year。修正：ytd 返回累计值。以 dt_date 为分组层级：SELECT dt_date, AGG(sales, 'ytd') FROM MODEL WHERE dt_date = date(current_date) GROUP BY dt_date。

P33. 计算期初至今累计值时指定了日期范围 #

错误：计算 YTD 时使用 WHERE dt_date BETWEEN date(current_date, 'start of year') AND date(current_date)。修正：将 WHERE dt_date = date(current_date) 与 AGG(sales, 'ytd') 搭配使用。日期范围由修饰符确定。

类别：编译与验证 #

P59. 未检查对比列就计算同比 #

错误：在 去年同期出厂价金额 的合计为零时使用 AGG(销售额, 'yoy')。修正：在承诺提供同比解读之前，先通过明细查询检查 SUM(去年同期出厂价金额)。

结果多出源数据最后一个月之后的月份 #

比较期间时，请明确指定报表的月份范围。全外连接可以保留任一期间中存在的分组。当 12 月的销售额作为上期销售额与 1 月对齐时，未限制日期范围的查询可能会包含 1 月，即使该月不在报表范围内。

此示例使用 2024 年 1 月至 2025 年 12 月的数据，每个月的五个类别都有销售额。模型定义了 revenue: SUM({amount})、名为 dt_month 的月份维度，以及 revenue_mom: '{revenue: pop}'。

SELECT dt_month, category, AGG(revenue), AGG(revenue_mom)
FROM MODEL
WHERE dt_month >= '2024-01-01' AND dt_month < '2026-01-01'
GROUP BY dt_month, category

在示例数据上，此查询返回 120 行，结果与手写的 SQL 一致。去掉日期筛选条件后，验证的查询返回 125 行。多出的五行属于 2026 年 1 月。这些分组只有 12 月的销售额参与计算，因此本期收入和增长率均为 NULL。

按类别核对两个期间的收入 #

如果报表用于比较两个期间的总收入，请保留在报表月份范围内任一期间有收入的类别。要查看两个期间的收入，请将 AGG({revenue: pp}) AS previous_revenue 添加到 SELECT 列表中。

类别 本期收入 上期收入
A 120 100
B NULL 40
C 30 NULL
合计 150 140

在此示例中，如果筛选后只保留本期有销售额的类别，B 会被排除，报表中显示的上期收入合计会降至 100。如果报表专门关注本期活跃类别，请使用该筛选条件，并在计算合计时采用相同的类别范围。要核对完整的比较结果，请按报表月份分别对每个收入列求和，并与源数据中对应月份的合计比较。总体增长率应根据两个期间的收入合计计算。

只有在该期间的数据完整，且业务规则将无销售视为零时，才将缺失值显示为零。用零填充会改变显示值。
