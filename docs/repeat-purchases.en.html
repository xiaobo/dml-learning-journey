Do two orders from the same supplier on the same day count as a repeat purchase?

Four stores ordered from you this week. A placed two orders on Monday. B placed one on Monday and another on Tuesday. Which stores would you count as repeat buyers in your weekly sales report?

Which stores qualify under each rule?

Count only orders placed this week. A store that bought last week and ordered just once this week doesn’t qualify under either rule.

Change an order to see which stores qualify. Each change starts from the original six orders.

Original six orders

A and B each placed two orders. A ordered twice on the same day. B ordered on two different days.

Count orders

50%

Qualifying stores this week: 2 of 4 (A, B).

A store qualifies if it placed at least two orders this week. DML counts distinct order IDs.

order_count: DISTINCTCOUNT({order_id})

A has two distinct order IDs and qualifies. order_count = 2

See the DML formulas for the store count and repeat purchase rate

{+d: store_id} tells DML to check each store separately. Each qualifying store counts once.

repeat_purchase_by_orders:
  type: measure
  abbr: repeat_purchase_by_orders
  formula: 'DISTINCTCOUNTIF({store_id}, {order_count: {+d: store_id}} > 1)'

Divide the number of qualifying stores (2) by the number that ordered this week (4). The repeat purchase rate is 50%.

repeat_purchase_rate_by_orders:
  type: measure
  abbr: repeat_purchase_rate_by_orders
  formula: 'DIVIDE(1.0 * {repeat_purchase_by_orders}, {active_stores})'

Check against your own weekly report

Choose the rule for your report. Run your existing SQL and the DML query on orders from the same week. Compare the stores first, then the rates. Two different lists can give the same percentage.

Try it with the six orders

The figures above come from DML queries. The script checks them against a separate SQL query on the same orders. It compares each store’s order count and days with an order, then checks both rates.

Download the six orders, DML model and verification script (ZIP)

Run the example

In the extracted folder, load the orders into DuckDB. Then check how often and on how many days each store ordered, followed by both repeat purchase rates.

dmlc -q setup.sql
dmlc -q --with-validation --model=repurchase.dml stores.sql
dmlc -q --with-validation --model=repurchase.dml rates.sql

Optional: check the results automatically in PowerShell.

./verify.ps1

The script checks the original orders, A’s date change and the split orders from C and D.

See the two queries used for the report

First, check how many orders each store placed and on how many days.

SELECT store_id, AGG(order_count), AGG(purchase_days)
FROM repurchase
GROUP BY store_id
ORDER BY store_id

Then check the number of repeat buyers and the repeat purchase rates.

SELECT AGG(active_stores), AGG(repeat_purchase_by_orders), AGG(repeat_purchase_by_days),
       AGG(repeat_purchase_rate_by_orders), AGG(repeat_purchase_rate_by_days)
FROM repurchase
Compare Tuesday’s orders with Monday’s

With dt_date set to Tuesday, pp returns the previous day’s order count. In the original six orders, Tuesday has two orders and Monday has four.

SELECT AGG(order_count), AGG(previous_day_order_count)
FROM repurchase
WHERE dt_date = '2025-02-04'
dmlc -q --model=repurchase.dml previous-day.sql
See the full DML model

The model reads the receipts table directly. Under each dataset column, abbr names the source column.

dialect: duckdb

RECEIPTS:
  type: dataset
  table: receipts
  dimension: [order_id]
  columns:
    order_id:
      abbr: order_id
    store_id:
      abbr: store_id
    dt_date:
      abbr: purchase_day
    units:
      abbr: units
  measures:
    order_count: DISTINCTCOUNT({order_id})
    purchase_days: DISTINCTCOUNT({dt_date})
    purchased_units: SUM({units})

active_stores:
  type: measure
  abbr: active_stores
  formula: 'DISTINCTCOUNTIF({store_id}, {purchased_units: {+d: store_id}} > 0)'

repeat_purchase_by_orders:
  type: measure
  abbr: repeat_purchase_by_orders
  formula: 'DISTINCTCOUNTIF({store_id}, {order_count: {+d: store_id}} > 1)'

repeat_purchase_by_days:
  type: measure
  abbr: repeat_purchase_by_days
  formula: 'DISTINCTCOUNTIF({store_id}, {purchase_days: {+d: store_id}} > 1)'

repeat_purchase_rate_by_orders:
  type: measure
  abbr: repeat_purchase_rate_by_orders
  formula: 'DIVIDE(1.0 * {repeat_purchase_by_orders}, {active_stores})'

repeat_purchase_rate_by_days:
  type: measure
  abbr: repeat_purchase_rate_by_days
  formula: 'DIVIDE(1.0 * {repeat_purchase_by_days}, {active_stores})'

previous_day_order_count:
  type: measure
  formula: '{order_count: pp}'
