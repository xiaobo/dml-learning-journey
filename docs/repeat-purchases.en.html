Do two orders on the same day count as a repeat purchase?

Four stores placed six orders in one week. Store A ordered twice on Monday. Store B ordered on Monday and again on Tuesday. Would you count A as a repeat buyer in the weekly report?

The original six orders

1AMonday1
2AMonday1
3BMonday1
4BTuesday1
5CMonday2
6DTuesday2

Does store A count?

In the original six orders, A and B both qualify if you count orders.

In the original six orders, only B qualifies if you count purchase days.

Repeat purchase rate (RPR)

All four stores bought something this week, so both rates use four as the denominator. Each row is one order for at least one unit. Both changes start from the original six orders.

Original orders

A placed both orders on Monday. A has two orders on one day. B has two orders on two days. Only B qualifies when you count purchase days.

repeat_by_order:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {order_count: {+d: store_id}} > 1)'

repeat_purchase_rate_by_order_count:
  type: measure
  formula: 'DIVIDE(1.0 * {repeat_by_order}, {active_stores})'

{+d: store_id} applies the test to each store. Each qualifying store counts once. Divide by the number of stores that bought this week.

Check the results before migrating

Agree on what the weekly report should count. Run your existing SQL and the DML query on the same orders. Compare the stores that qualify, then compare the rates. The download includes the ledger, both DML definitions, an independent SQL query and a script to check all three cases.

The figures come from running the DML queries for all three cases. An independent SQL query checked the results against the same orders.

See the two queries used for these results
SELECT store_id, AGG(order_count), AGG(purchase_days)
FROM repurchase
GROUP BY store_id
ORDER BY store_id
SELECT AGG(active_stores), AGG(repeat_by_order), AGG(repeat_by_day),
       AGG(repeat_purchase_rate_by_order_count), AGG(repeat_purchase_rate_by_purchase_days)
FROM repurchase

dialect: duckdb

RECEIPTS:
  type: dataset
  table: receipts
  dimension: [order_id]
  columns:
    order_id:
    store_id:
    purchase_day:
    units:
  measures:
    order_count: DISTINCTCOUNT({order_id})
    purchase_days: DISTINCTCOUNT({purchase_day})
    purchased_units: SUM({units})

active_stores:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {purchased_units: {+d: store_id}} > 0)'

repeat_by_order:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {order_count: {+d: store_id}} > 1)'

repeat_by_day:
  type: measure
  formula: 'DISTINCTCOUNTIF({store_id}, {purchase_days: {+d: store_id}} > 1)'

repeat_purchase_rate_by_order_count:
  type: measure
  formula: 'DIVIDE(1.0 * {repeat_by_order}, {active_stores})'

repeat_purchase_rate_by_purchase_days:
  type: measure
  formula: 'DIVIDE(1.0 * {repeat_by_day}, {active_stores})'
