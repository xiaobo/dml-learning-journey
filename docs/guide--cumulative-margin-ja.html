月ごとの粗利率を平均しても、期間全体の粗利率にならない理由

このページの内容
  • 北部の売上を使った例
  • 計算の流れを確認する
  • パーセントとポイントの違い

期間全体の売上と原価をそれぞれ合計し、粗利の合計を売上の合計で割ります。月ごとの粗利率を単純平均すると、売上が違っても各月の重みが同じになります。

北部の売上を使った例 #

期間 売上 原価 粗利率
2025 年 1 月 100 60 40%
2025 年 2 月 300 240 20%
1 月と 2 月の合計 400 300 25%

サンプルデータで計算すると、累計粗利率は (400 − 300) / 400 = 25% です。40% と 20% の単純平均は 30% です。毎月の売上が等しい場合などは一致しますが、一般には異なります。

計算の流れを確認する #

粗利率のアニメーションで North を選び、4 番目のステップを開きます。月別から年初以降の累計に切り替えると、売上は 300 から 400、原価は 240 から 300、粗利率は 20% から 25% に変わります。

モデルでは ytd を使い、年初からの純売上高と売上原価をそれぞれ集計します。累計の純売上高から累計の売上原価を引き、累計の純売上高で割ると、年初来の粗利率が求められます。

DML モデルの全体を見る 
dialect: mssql

売上と原価:
  type: dataset
  table: TABLE_PROFITABILITY
  dimension: [売上明細番号]
  columns:
    売上明細番号:
      abbr: id
    元データの地域:
      abbr: region
    地域: '{元データの地域}'
    dt_month:
      abbr: dt_month
    売上金額:
      abbr: revenue_amount
    原価金額:
      abbr: cost_amount
  measures:
    純売上高: SUM({売上金額})
    売上原価: SUM({原価金額})

粗利益:
  type: measure
  formula: '{純売上高} - {売上原価}'

粗利率:
  type: measure
  formula: 'DIVIDE({粗利益}, {純売上高})'

年初来粗利率:
  type: measure
  formula: 'DIVIDE({純売上高: ytd} - {売上原価: ytd}, {純売上高: ytd})'

前年同期の年初来粗利率:
  type: measure
  formula: 'DIVIDE({純売上高: {ytd, ya}} - {売上原価: {ytd, ya}}, {純売上高: {ytd, ya}})'

粗利率の前年差ポイント:
  type: measure
  formula: '100 * ({年初来粗利率} - {前年同期の年初来粗利率})'

パーセントとポイントの違い #

北部の前年同期の累計粗利率は 20% です。20% から 25% への上昇幅は 5 ポイント、相対的な増加率は (25% / 20%) − 1 = 25% です。レポートではどちらを示すかを明記してください。

モデルと計算例、比較用クエリ、コンパイル記録も参照してください。記録の対象は厳密モードでのコンパイルと生成された SQL の確認です。元テーブルの金額には小数型を使います。売上が 0 の場合は NULL になり、前年データがなければ欠損のままです。
