月ごとの粗利率を平均しても、期間全体の粗利率にならない理由

このページの内容
  • 北部の売上を使った例
  • 計算の流れを確認する
  • パーセントとポイントの違い

期間全体の売上と原価をそれぞれ合計し、粗利の合計を売上の合計で割ります。月ごとの粗利率を単純平均すると、売上が違っても各月の重みが同じになります。

北部の売上を使った例 #

期間 売上 原価 粗利率
2025 年 1 月 100 60 40%
2025 年 2 月 300 240 20%
1 月と 2 月の合計 400 300 25%

サンプルデータで計算すると、累計粗利率は (400 − 300) / 400 = 25% です。40% と 20% の単純平均は 30% です。毎月の売上が等しい場合などは一致しますが、一般には異なります。

計算の流れを確認する #

粗利率のアニメーションで North を選び、4 番目のステップを開きます。月別から年初以降の累計に切り替えると、売上は 300 から 400、原価は 240 から 300、粗利率は 20% から 25% に変わります。

定義済みの粗利率に formula: '{gross_margin: ytd}' を指定すると、累計額から粗利率を計算し直します。この記法は DuckDB で実行し、独立の SQL と結果を照合済みです。SQL Server についてはコンパイル結果を確認しています。

DML モデルの全体を見る 
dialect: mssql

FACT_PROFITABILITY:
  type: dataset
  table: TABLE_PROFITABILITY
  dimension: [id]
  columns:
    id:
    region:
    dt_month:
    revenue_amount:
    cost_amount:
  measures:
    net_revenue: SUM({revenue_amount})
    sales_cost: SUM({cost_amount})

gross_profit:
  type: measure
  formula: '{net_revenue} - {sales_cost}'

gross_margin:
  type: measure
  formula: 'DIVIDE({gross_profit}, {net_revenue})'

gross_margin_ytd:
  type: measure
  formula: 'DIVIDE({net_revenue: ytd} - {sales_cost: ytd}, {net_revenue: ytd})'

gross_margin_prior_ytd:
  type: measure
  formula: 'DIVIDE({net_revenue: {ytd, ya}} - {sales_cost: {ytd, ya}}, {net_revenue: {ytd, ya}})'

margin_change_pp:
  type: measure
  formula: '100 * ({gross_margin_ytd} - {gross_margin_prior_ytd})'

パーセントとポイントの違い #

北部の前年同期の累計粗利率は 20% です。20% から 25% への上昇幅は 5 ポイント、相対的な増加率は (25% / 20%) − 1 = 25% です。レポートではどちらを示すかを明記してください。

モデルと計算例、比較用クエリ、コンパイル記録も参照してください。記録の対象は厳密モードでのコンパイルと生成された SQL の確認です。元テーブルの金額には小数型を使います。売上が 0 の場合は NULL になり、前年データがなければ欠損のままです。
