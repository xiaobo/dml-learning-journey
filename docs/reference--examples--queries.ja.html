入門例では共通の売上モデルを使用します。このモデルは売上高と一覧に示した取引列を提供しますが、ソースデータは作成しません。日付を使う例では現在の日付を基準とするため、過去のテストデータでは行が返らない場合があります。

例を実行するための前提条件: 基本クエリ、売上の期間比較、順位、構成比、商品数の集計には、このモデルを使用します。経費の例には追加で指標 費用 が必要です。未払い残高の例には 顧客 と 未払額、アカウント別の成長率の例には 勘定科目 と 収益 が必要です。これらは環境に合わせて調整するための断片で、共通モデルに追加してそのまま実行できるものではありません。固定の日付と期待される結果が揃った実行可能なデータセットには、検証済みの売上演習を使用してください。

基本クエリ #

売上合計 #

SELECT AGG(売上高) FROM MODEL

地域別の売上 #

SELECT 地域, AGG(売上高) FROM MODEL GROUP BY 地域

今月の売上 #

SELECT AGG(売上高) FROM MODEL WHERE dt_month = date(current_date, 'start of month')

地域別の今月の売上 #

SELECT 地域, AGG(売上高)
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 地域

明細クエリ：支払い済みの取引 #

SELECT dt_date, 取引番号, 売上金額, 支払済
FROM MODEL.取引明細
WHERE 支払済 = 1
ORDER BY dt_date DESC

時間修飾子 #

今月と先月の比較 #

SELECT dt_month,
       AGG(売上高) as 当月売上高,
       AGG(売上高, 'pp') as 前月売上高,
       AGG(売上高, 'pop') as 前月比増減率
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY dt_month

今月と前年同月の比較 #

SELECT dt_month,
       AGG(売上高) as 当月売上高,
       AGG(売上高, 'ya') as 前年同月売上高,
       AGG(売上高, 'yoy') as 前年同期比増減率
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY dt_month

年初来の成長率 #

SELECT dt_date,
       AGG(売上高, 'ytd') as 当年累計売上高,
       AGG(売上高, 'ytd', 'ya') as 前年同期累計売上高,
       AGG(売上高, 'ytd', 'yoy') as 累計売上高前年同期比
FROM MODEL
WHERE dt_date = date(current_date)
GROUP BY dt_date

修飾子の重ねがけに注目してください。'ytd', 'ya' は、前年の年初から前年の同日までの期間を指します。

直近12か月の移動合計 #

SELECT dt_month, AGG(売上高), AGG({売上高: mat}) AS 移動売上高
FROM MODEL
GROUP BY dt_month
ORDER BY dt_month DESC
LIMIT 12

特定の月または四半期 #

-- August this year
SELECT AGG(費用) FROM MODEL WHERE dt_month = date(current_date, 'start of year', '+7 months')

-- Q2 this year
SELECT AGG(費用) FROM MODEL WHERE dt_quarter = date(current_date, 'start of year', '+1 quarter')

.dml での修飾子のネスト #

# In model.dml
年初来売上高:
    type: measure
    formula: '{売上高: ytd}'

前年同期累計売上高:
    type: measure
    formula: '{売上高: {ytd: ya}}'

-- In query
SELECT dt_date, AGG(年初来売上高), AGG(前年同期累計売上高)
FROM MODEL
WHERE dt_date = date(current_date)
GROUP BY dt_date

要点：時間修飾子には、時間コンテキストが確定していることと、マクロの前提条件を満たしていることが必要です。時間フィルターでも時間コンテキストを指定できます。yoy と pop は成長率を小数で返します（0.15 = 15%）。pp と ya は、比較対象となる過去の期間の指標値そのものを返します。日付を手動で計算するよりも、修飾子を使うことを推奨します。

順位とフィルター #

売上上位10商品 #

SELECT 商品, AGG(売上高)
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品
ORDER BY AGG(売上高) DESC
LIMIT 10

順位修飾子の使用 #

SELECT 商品, AGG(売上高), AGG({売上高: rank}) AS 売上順位
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品

{売上高: rank} は、クエリ結果内で各商品の売上が何位かを返します。順位は売上の降順で決まります。

選択した期間内の順位 #

SELECT 商品,
       AGG(売上高) as 期間売上高,
       AGG({売上高: rank}) as 選択期間順位
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品

このクエリはすでに商品だけでグループ化しています。月のフィルターを維持したまま、売上高 を直接順位付けしてください。時間の集計レベルを取り除く必要はありません。グループ化フィールドを取り除くことと、時間フィルターを取り除くことは別の操作です。

順位による絞り込み #

SELECT 商品, AGG(売上高)
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品
HAVING AGG({売上高: rank}) <= 10

HAVING は集計後に絞り込むため、この句で rank を使用できます。

HAVING 句：未払い残高のある顧客 #

SELECT 顧客, AGG(未払額)
FROM MODEL
GROUP BY 顧客
HAVING AGG(未払額) > 0

要点：rank は RANK() OVER (ORDER BY measure DESC) を返します。rank_asc は値の昇順で順位を返します。順位付けの前に時間ディメンションや他のディメンションを取り除くには、-d を使用します。順位が N 位以内の結果を動的に絞り込むには、順位修飾子を HAVING と組み合わせます。

総計に占める割合（pot） #

SELECT 商品, AGG(売上高) AS 売上高,
       AGG(売上高, 'rank') AS 売上順位,
       AGG({売上高: pot}) AS 合計構成比
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 商品
ORDER BY AGG(売上高, 'rank')

pot は measure / grand です。パレート分析で使う累積構成比はシステムの fn マクロではありません。累計が必要な場合は、Model Query SQL で OVER() を使用します。

RFM と共起パターン #

RFM 分析と共起分析については、細かい集計レベルでの集計例を参照してください。

dt を含まないディメンション #

地域別の売上（全期間） #

SELECT 地域, AGG(売上高) FROM MODEL GROUP BY 地域

地域別の商品構成比（時間によるグループ化なし） #

SELECT 地域, 商品, AGG(売上高)
FROM MODEL
GROUP BY 地域, 商品

選択した期間と全履歴の比較 #

-- Selected month: retain the month filter.
SELECT 地域, 商品, AGG(売上高) AS 選択期間売上高
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 地域, 商品

-- All history: remove the month filter, retain the same grouping.
SELECT 地域, 商品, AGG(売上高) AS 全期間売上高
FROM MODEL
GROUP BY 地域, 商品

これらは別々のクエリとして実行してください。-d はグループ化を取り除きますが、時間フィルターは維持します。これらのクエリは時間でグループ化しないため、-d: dim_dt は不要です。ここで個々の指標から時間の集計レベルを取り除こうとすると、検証に使用したコンパイラーによって拒否されます。分母に限ってグループ化とフィルターを取り除く方法については、ディメンション修飾子とフィルター修飾子を参照してください。

期間単位の変換 #

SELECT dt_year,
       AGG({売上高: {dim_dt as quarter: pp}}) as 前四半期の四半期売上高
FROM MODEL
WHERE dt_year = '2024-01-01'
GROUP BY dt_year

dim_dt as quarter を指定すると、クエリが年単位でグループ化されていても、修飾子 pp は四半期単位で処理します。指標を変更後の集計レベル（四半期）で評価してから、その結果をクエリの集計レベル（年）のデータに結合します。

注記: dim_dt as <grain> が役に立つのは、変更後の時間の集計レベルがクエリの時間の集計レベルと異なる場合に限ります。クエリがすでに dt_quarter でグループ化されている場合、dim_dt as quarter: pp は不要な指定として拒否されます。この場合は AGG({売上高: pp}) を直接使用してください。

要点：時間フィルターのないクエリは、すべての履歴データを対象にします。-d: dim_dt は、指標の評価に使うディメンションから現在有効な時間フィールドを取り除きます。有効な時間フィールドを指定するには、dt_date のような個別のフィールド名ではなく dim_dt を使います。-d で取り除けるのは、現在のクエリのグループ化に含まれるディメンションフィールドだけです。dim_dt as <grain> は、1 つの指標参照の時間の集計レベルを変更します。組み合わせる際は、同じ行にあっても、時間ディメンションのない指標と時間ディメンションのある指標を比較できない場合があります。

比較パターン #

前の期間との比較 #

SELECT AGG(売上高) as 当月売上高, AGG(売上高, 'pp') as 前月売上高
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')

アカウント別の成長率 #

SELECT 勘定科目, AGG(収益) as current, AGG(収益, 'pp') as previous
FROM MODEL
WHERE dt_month = date(current_date, 'start of month')
GROUP BY 勘定科目
HAVING AGG(収益, 'pop') > 0.10  -- 10% growth

年初来と前年の比較 #

SELECT AGG(売上高, 'ytd') as 当年累計, AGG(売上高, 'ytd', 'ya') as 前年同期累計
FROM MODEL
WHERE dt_date = date(current_date)
GROUP BY dt_date

条件付きカウント #

修飾子は列ではなく指標に適用します。条件式の中で、指標に {+d: 商品} を適用します。

-- Count of products with per-商品 売上高 above threshold
SELECT DISTINCTCOUNTIF(商品, AGG({売上高: {+d: 商品}}) > 1000) as 商品数 FROM MODEL

または、.dml で formula: 'DISTINCTCOUNTIF({商品}, {売上高: {+d: 商品}} > 1000)' を使って一度定義してから、SELECT AGG(high_sales_product_count) FROM MODEL でクエリを実行します。
