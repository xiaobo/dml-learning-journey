查询示例共用的模型

本页目录

    入门部分的查询示例把这个模型保存为 model.dml。后面的例子如果还需要其他定义，会单独列出。编译通过后，还要检查源数据的键是否唯一，以及查询结果是否符合预期。

    # model.dml (shared)
transactions:
    type: dataset
    table: fact_transactions
    dimension:
        - transaction_id
    columns:
        transaction_id:
        dt_date:
        product:
        region:
        category:
        amount:
        quantity:
        is_paid:

sales:
    type: measure
    dataset: transactions
    formula: SUM({amount})
