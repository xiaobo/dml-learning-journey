Run and check the sales report

On this page

    Download the DuckDB exercise package

    In the extracted folder, run these commands. The first loads the data into DuckDB. The second checks the model and runs the report.

    dmlc -q setup.sql
dmlc -q --with-validation --model=model.dml query.sql

    Optional: check the results automatically in PowerShell.

    ./verify.ps1

    The script builds the exercise database in the extracted directory and then runs strict compilation, standalone validation, and checked query execution in order. When all three exit codes are 0 and result_matches in verification.json is true, the returned two rows and six columns match expected.csv.

    In verification.json, version identifies the dmlc build and compiler_sha256 identifies the executable used for the check. To repeat the exercise, extract it into a fresh folder.

    This exercise uses the eight sales records from the interactive journey. To use your own database, follow the compile and validation steps.
