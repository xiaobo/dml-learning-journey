Run and check the sales report

On this page

    Download the DuckDB exercise package and extract it into a new, writable directory. Prepare Python, duckdb, and a dmlc.exe that supports --with-validation, then run in the extracted directory:

    py -m pip install duckdb==1.5.5
py verify.py C:/path/to/dmlc.exe

    The script builds the exercise database in the extracted directory and then runs strict compilation, standalone validation, and checked query execution in order. When all three exit codes are 0 and result_matches in verification.json is true, the returned two rows and six columns match expected.csv.

    The package records dmlc 0.3.16 for Windows amd64 (build 2026-11-27 02:57:23 Z). The script records the build and SHA-256 it actually used. To run the exercise again, extract it into a fresh directory.

    This exercise uses the eight sales records from the interactive journey. To use your own database, follow the compile and validation steps.
