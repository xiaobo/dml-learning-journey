duplicate_key
重複したキーを調べる

検証結果にあるデータセット名とキーを確認します。モデルでは一意と定義されていますが、実際のデータに同じキーの行が複数あります。

重複しているキーを探す

地域テーブル DIM のキーは id と region の組み合わせです。東部と西部で ID 1 が 1 回ずつ使われていても問題ありません。同じ組み合わせが複数ないか調べます。

SELECT id, region, COUNT(*) AS matches
FROM DIM
GROUP BY id, region
HAVING COUNT(*) > 1;

レポートの数字はどう変わる？

東部の売上は 10 の 1 件だけです。地域テーブルに (1, east) が 2 行あると、SQL で結合したときに両方が同じ売上に一致し、合計が 20 になります。西部の合計は 20 のままです。

修正後にもう一度確認する

まず 2 行とも必要な記録かを確認します。両方とも正しければ、モデルで指定したキーに不足がないかを調べます。この例では東部の 2 行目は誤って追加されたものです。地域テーブルを修正して再検証し、レポートを実行します。東部が 10、西部が 20 になれば、元の売上と一致します。
