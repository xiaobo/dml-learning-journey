最初のモデルクエリをコンパイルする

このページの内容
  • コンパイラを確認する
  • モデルを定義する
  • クエリを記述する
  • クエリをコンパイルする
  • 結果を確認する

売上モデルを作成し、地域別の合計を返すクエリをコンパイルします。dmlc.exeがインストールされていることと、書き込み可能な作業ディレクトリが必要です。このチュートリアルでは、データベースに接続せずにSQLをコンパイルします。

コンパイラを確認する #

dmlc.exeをインストールし、そのディレクトリをPATHに追加します。PowerShellを開き、作業ディレクトリを作成する前に実行ファイルのパスを保存します。

$dmlc = (Get-Command dmlc.exe).Source
& $dmlc --version

表示されたバージョンとビルド日時を控えておくと、どのコンパイラで得た結果か後から確認できます。

次に、ファイルを保存するためのディレクトリを新規作成します。

New-Item -ItemType Directory -Path first-query
Set-Location first-query

プロンプトの末尾がfirst-queryになります。

モデルを定義する #

次の内容をmodel.dmlとして保存します。

dialect: mssql

売上明細:
  type: dataset
  table: TABLE_SALES
  dimension: [売上明細番号]
  columns:
    売上明細番号:
      abbr: id
    地域:
      abbr: region
    売上金額:
      abbr: amount
  measures:
    売上高: SUM({売上金額})
    売上件数: COUNT(1)

一件当たり売上高:
  type: measure
  formula: 'DIVIDE({売上高}, {売上件数})'

売上明細は、売上明細番号ごとにソース行が1行あると宣言します。売上高と売上件数はこれらの行を集計します。一件当たり売上高は前者の集計結果を後者の集計結果で割ります。

次に、モデルを lint でチェックします。

& $dmlc --lint model.dml --json
$LASTEXITCODE

プロセスは終了コード0で終了します。lint で指摘が報告された場合は、先に進む前に、保存したファイルを上記のモデルと見比べてください。

クエリを記述する #

次の内容をquery.sqlとして、model.dmlと同じディレクトリに保存します。

SELECT 地域, AGG(売上高), AGG(一件当たり売上高)
FROM MODEL
GROUP BY 地域

FROM MODELでmodel.dmlを選択します。結果の各行は1つの地域を表します。

クエリをコンパイルする #

次に、クエリを厳格モードでコンパイルします。

& $dmlc --compile --strict query.sql --model=model.dml --json --artifacts=gen
$LASTEXITCODE

JSON に status: ok と exitCode: 0 が表示され、diagnostics にはエラーや警告がありません。data.sql を見ると、地域別に売上を集計し、平均を求める処理を確認できます。結果の列は 地域、売上高、一件当たり売上高 です。

コンパイラは、情報レベルの診断メッセージDATASET_GRAIN_UNVERIFIEDを出力する場合があります。ここでは、物理テーブルTABLE_SALESを確認せずに、宣言されたモデルをコンパイルしました。

結果を確認する #

SQLの生成ファイルをgenディレクトリ内で開きます。集計式と地域によるグループ化を確認します。これで、モデルとそれを利用するクエリが完成し、生成されたSQLを確認できます。

クエリを実行するには、宣言されたソーステーブルにアクセスできる接続を使用します。接続先でキーを検証してクエリを実行する手順は、dmlc CLIを使うを参照してください。基本概念では、モデル層とクエリ層の関係を説明します。
