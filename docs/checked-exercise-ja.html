    DuckDB 演習用パッケージをダウンロードし、書き込み可能な新しいフォルダーに展開します。Python、duckdb、--with-validation に対応した dmlc.exe が必要です。展開先で次のコマンドを実行します。

    py -m pip install duckdb==1.5.5
py verify.py C:/path/to/dmlc.exe

    スクリプトは展開先に演習用データベースを作り、厳密モードでのコンパイル、データ検証、検証付きのクエリ実行を順に行います。3 つの終了コードがすべて 0 で、verification.json の result_matches が true なら、結果の 2 行 6 列は expected.csv と一致しています。

    同梱の記録は Windows amd64 版 dmlc 0.3.16（ビルド 2026-11-27 02:57:23 Z）で取得しました。スクリプトは実際に使用したビルドと SHA-256 を記録します。再実行する場合は新しいフォルダーに展開してください。

    この演習ではチュートリアルと同じ 8 件の売上データを使います。自分のデータベースで確認する場合は、コンパイルと検証の手順を参照してください。
