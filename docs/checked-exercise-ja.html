    DuckDB 演習用パッケージ

    展開したフォルダーで次のコマンドを実行します。一つ目はデータをDuckDBに読み込み、二つ目はモデルを検証してレポートを実行します。

    dmlc -q setup.sql
dmlc -q --with-validation --model=model.dml query.sql

    必要に応じて、PowerShellで結果を自動照合できます。

    ./verify.ps1

    スクリプトは展開先に演習用データベースを作り、厳密モードでのコンパイル、データ検証、検証付きのクエリ実行を順に行います。3 つの終了コードがすべて 0 で、verification.json の result_matches が true なら、結果の 2 行 6 列は expected.csv と一致しています。

    verification.json の version で検証に使った dmlc のバージョンを、compiler_sha256 で実行ファイルの SHA-256 を確認できます。再度実行するときは、新しいフォルダーに展開してください。

    この演習ではチュートリアルと同じ 8 件の売上データを使います。自分のデータベースで確認する場合は、コンパイルと検証の手順を参照してください。
