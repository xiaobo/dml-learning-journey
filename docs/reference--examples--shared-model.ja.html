クエリの例で使う共通モデル

このページの内容

    最初のクエリの例では、このモデルを model.dml として使います。以降の例でほかの定義が必要な場合は、各例に記載しています。コンパイル後は、元データのキーに重複がないか、集計結果が期待値と一致するかを別途確認してください。

    # model.dml (shared)
transactions:
    type: dataset
    table: fact_transactions
    dimension:
        - transaction_id
    columns:
        transaction_id:
        dt_date:
        product:
        region:
        category:
        amount:
        quantity:
        is_paid:

sales:
    type: measure
    dataset: transactions
    formula: SUM({amount})
