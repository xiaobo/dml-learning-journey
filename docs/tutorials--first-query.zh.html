编译第一条模型查询

我们将构建销售模型，并编译一条按地区返回合计值的查询。开始前需安装 dmlc.exe，并准备一个可写的工作目录。本教程在不连接数据库的情况下编译 SQL。

确认编译器 #

安装 dmlc.exe，并将其所在目录添加到 PATH。打开 PowerShell，然后先保存可执行文件的路径，再创建工作目录。

$dmlc = (Get-Command dmlc.exe).Source
& $dmlc --version

记下这里显示的版本和构建时间，之后可以用来核对生成结果的编译器。

接下来，新建一个目录来存放本教程的文件。

New-Item -ItemType Directory -Path first-query
Set-Location first-query

此时，命令提示符以 first-query 结尾。

定义模型 #

将以下内容保存为 model.dml。

dialect: mssql

销售明细:
  type: dataset
  table: TABLE_SALES
  dimension: [销售明细编号]
  columns:
    销售明细编号:
      abbr: id
    地区:
      abbr: region
    销售金额:
      abbr: amount
  measures:
    销售额: SUM({销售金额})
    销售笔数: COUNT(1)

每笔平均销售额:
  type: measure
  formula: 'DIVIDE({销售额}, {销售笔数})'

销售明细 声明每个 销售明细编号 对应一条源数据行。销售额 和 销售笔数 对这些行进行聚合。每笔平均销售额 将前者的聚合结果除以后者的聚合结果。

接下来，对模型运行 lint 检查。

& $dmlc --lint model.dml --json
$LASTEXITCODE

进程以退出码 0 结束。如果 lint 报告了问题，请先将保存的文件与上面的模型进行比较，再继续。

编写查询 #

将以下内容保存为 query.sql，并将该文件放在 model.dml 所在的目录中。

SELECT 地区, AGG(销售额), AGG(每笔平均销售额)
FROM MODEL
GROUP BY 地区

FROM MODEL 选择 model.dml。结果中的每一行代表一个地区。

编译查询 #

接下来，在严格模式下编译查询。

& $dmlc --compile --strict query.sql --model=model.dml --json --artifacts=gen
$LASTEXITCODE

JSON 中会显示 status: ok 和 exitCode: 0，diagnostics 中没有错误或警告。在 data.sql 中可以看到查询怎样按地区汇总销售额、计算平均值。输出列为 地区、销售额 和 每笔平均销售额。

编译器可能会输出信息级诊断消息 DATASET_GRAIN_UNVERIFIED。我们编译了已声明的模型，但没有检查物理表 TABLE_SALES。

检查结果 #

打开生成的 SQL 文件，该文件位于 gen 目录下。找到聚合表达式和按 地区 分组的子句。现在，模型和使用该模型的查询都已完整，生成的 SQL 也可供检查。

要执行查询，请使用能够访问已声明源表的数据库连接。请按照使用 dmlc CLI中的步骤，在连接的数据库上验证键并执行查询。核心概念介绍了模型层和查询层如何配合。
