Shared model for query examples

On this page

    The introductory query examples use this model as model.dml. Later domain fragments name additional dependencies. Compilation does not establish source-key uniqueness or result correctness.

    # model.dml (shared)
transactions:
    type: dataset
    table: fact_transactions
    dimension:
        - transaction_id
    columns:
        transaction_id:
            abbr: transaction_id
        dt_date:
            abbr: dt_date
        product:
            abbr: product
        region:
            abbr: region
        category:
            abbr: category
        amount:
            abbr: amount
        quantity:
            abbr: quantity
        is_paid:
            abbr: is_paid

sales:
    type: measure
    dataset: transactions
    formula: SUM({amount})
