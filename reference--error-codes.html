DMLC Error Codes Reference

Implementation note: kept in sync with Java error enums. Full tool response shapes: MCP Contract (CLI + MCP). Explain-change diagnostics: ../../../dmlc_jdbc/docs/explain-change.md.

Path display convention

All user-visible paths (CLI stderr, MCP message / details, scrubbed logs) use forward slashes (/) on every platform:

  • User input such as ..\data or ../data is normalized to ../data in errors.
  • Workspace placeholders use <workspaceFolder>/relative/path (never backslashes under the placeholder).
  • Resolved filesystem paths prefer cwd-relative form when possible (WorkspaceUtils.toUserFacingPath).

Internal resolution still uses java.nio.file.Path; only display and serialized error fields are normalized.

Error Code Categories

Category Description CLI Exit Code
INVALID_INPUT Input validation failed - user can fix and retry 64
VALIDATION User-level validation failed (parsed OK, but arguments are invalid) 65
NOT_FOUND Requested resource not found 66
CONFIG Configuration error (missing/invalid config, unknown connection id, etc.) 78
TIMEOUT Operation timed out - retry with different parameters 69
COMPILE Compilation failed (syntax / model error) 2
EXECUTION Execution failed but may succeed on retry 70
INTERNAL Unexpected internal error - should be reported 70
BLOCKED Operation blocked by policy or state 77

Error Codes

File I/O Errors

FILE_NOT_FOUND

  • Category: NOT_FOUND
  • Code: FILE_NOT_FOUND
  • Common Causes: File path is incorrect, file does not exist, file is outside workspace folder
  • Suggested Fixes: Verify file path is correct and within workspace folder
  • Example: File not found: /path/to/file.dml

FILE_ALREADY_EXISTS

  • Category: BLOCKED
  • Code: FILE_ALREADY_EXISTS
  • Common Causes: Attempting to create a file that already exists without overwrite
  • Suggested Fixes: Use overwrite flag or choose a different file name
  • Example: File already exists: /path/to/file.csv

UNSUPPORTED_FILE_TYPE

  • Category: INVALID_INPUT
  • Code: UNSUPPORTED_FILE_TYPE
  • Common Causes: Attempting to use an unsupported file format
  • Suggested Fixes: Use supported file type (parquet, csv, xlsx)
  • Example: Unsupported file type: .txt. Supported types: .csv, .xlsx, .parquet

PATH_OUTSIDE_WORKSPACE

  • Category: BLOCKED
  • Code: PATH_OUTSIDE_WORKSPACE
  • Common Causes: File path is outside the workspace folder (including ../ traversal, absolute paths on another drive, or symlinks that resolve outside the workspace)
  • Suggested Fixes: Use a relative path within the workspace folder
  • Example: File path must be within workspace: ../outside/file.csv. Workspace folder: <workspaceFolder> (same message for read paths via resolveFilename and write paths via resolveOutputPath)
  • Path display: User-facing paths in errors and MCP/CLI payloads use forward slashes (/) on all platforms, including <workspaceFolder>/relative/path placeholders.
  • Notes: When a workspace folder is configured (MCP workspace / workspaceRoots, or CLI WORKSPACE_FOLDER), relative traversal outside that folder is blocked on both MCP and CLI. With multiple workspaceRoots, output paths may be absolute under any configured root.
  • Breaking change (list_models): Unresolvable dataFiles entries now return PATH_OUTSIDE_WORKSPACE or INVALID_PARAMS and abort the tool instead of emitting a warning and continuing with partial results.

NO_SHEETS_IN_EXCEL

  • Category: INVALID_INPUT
  • Code: NO_SHEETS_IN_EXCEL
  • Common Causes: Excel file has no sheets or is corrupted
  • Suggested Fixes: Provide a valid Excel file with at least one sheet
  • Example: Excel file has no sheets: /path/to/file.xlsx

Connection Errors

CONNECTION_NOT_FOUND

  • Category: CONFIG
  • Code: CONNECTION_NOT_FOUND
  • Common Causes: Connection ID does not exist in connections.json
  • Suggested Fixes: List available connections and pick a valid connection id, or add connection to connections.json
  • Example: Connection not found: production. Available connections: [dev, staging]

LIST_CONNECTIONS_ERROR

  • Category: EXECUTION
  • Code: LIST_CONNECTIONS_ERROR
  • Common Causes: Failed to list available connections due to database or config error
  • Suggested Fixes: Check connection configuration and database accessibility
  • Example: Failed to list connections: Connection refused

Query Execution Errors

EXECUTION_ERROR

  • Category: EXECUTION
  • Code: EXECUTION_ERROR
  • Common Causes: Query execution failed due to SQL error, data issue, database problem, or stale materialize cache after model changes
  • Suggested Fixes: Check query syntax, data types, and database connectivity. If the message mentions obsolete materialize semver or pls re-setup related model, run dmlc -s <model.dml> --connection=<id> then retry the query with the same --model.
  • Example: Execution failed: Column 'invalid_column' does not exist
  • Example (materialize obsolete): materialize abort: procedure PROC_M__CACHED_SALES is obsolete since semver (...) is different from expect: ..., pls re-setup related model

EXECUTION_INTERRUPTED

  • Category: EXECUTION
  • Code: EXECUTION_INTERRUPTED
  • Common Causes: Query was interrupted by user or system
  • Suggested Fixes: Retry the query
  • Example: Query execution interrupted

TIMEOUT_ERROR

  • Category: TIMEOUT
  • Code: TIMEOUT_ERROR
  • Common Causes: Query took too long to execute
  • Suggested Fixes: Increase timeoutSeconds parameter or simplify query, consider adding materialize to improve performance
  • Example: Query timed out after 30 seconds

Compilation Errors

COMPILE_ERROR

  • Category: VALIDATION
  • Code: COMPILE_ERROR
  • Common Causes: DML syntax error, model validation error, SQL generation error; illegal modifier composition (e.g. same-dimension +d with -d/-df in one modifier object — language contract: fail loudly, see dml-core-spec §4.5 / pitfalls P79)
  • Suggested Fixes: Fix compilation errors, check model.dml exists in workspace folder, review generated SQL in error.details.generatedSql; for conflicting +d/-d/-df, rewrite to one explicit intent instead of relying on cancel
  • Example: Compilation failed — see details.compilationErrors
  • Notes: The 2026-10-16 same-field +d conflict probes produce no error diagnostic and exit 0. The required rejection is not implemented in those cases. A future diagnostic needs its own verified structured code. See release evidence.

COMPILE_TIMEOUT

  • Category: TIMEOUT
  • Code: COMPILE_TIMEOUT
  • Common Causes: Compilation took too long to complete
  • Suggested Fixes: Simplify DML model, reduce complexity, increase timeout
  • Example: Compilation timed out after 30 seconds

VALIDATION_ERROR

  • Category: VALIDATION
  • Code: VALIDATION_ERROR
  • Common Causes: Validation failed for parameters or configuration
  • Suggested Fixes: Fix invalid parameters or configuration
  • Example: Validation failed — see details.validationErrors

Generation Errors

MODEL_RESOLUTION_ERROR

  • Category: NOT_FOUND
  • Code: MODEL_RESOLUTION_ERROR
  • Common Causes: Cannot find <FROM>.dml beside the SQL / under --model=<dir> / on the model path; or --model=acme.dml was used with FROM MODEL (file/FROM mismatch — exit 65); or explain_change was given a directory
  • Suggested Fixes: For query/compile/validate, pass a directory that contains the right .dml, or pass a file whose name matches FROM. For explain_change / setup, pass a .dml file. Or call list_models, then pass the directory containing .dml files as run_query.model for DML model queries only (not native SQL).
  • Example: model file "acme.dml" does not match FROM "MODEL" (expected "MODEL.dml").

FILTER_VALIDATION_ERROR

  • Category: VALIDATION
  • Code: FILTER_VALIDATION_ERROR
  • Common Causes: Filter syntax error or invalid field name
  • Suggested Fixes: Fix filter field name or syntax
  • Example: Filter validation failed: invalid field 'dt_invalid'

Dimension Validation Errors

DIMENSION_NOT_UNIQUE

  • Category: VALIDATION
  • Code: DIMENSION_NOT_UNIQUE
  • Common Causes: The complete dataset dimension value combination occurs more than once, or a range-based lookup can match overlapping source rows
  • Suggested Fixes: Fix the source key, dataset dimension: field list, overlapping ranges, or source data, then rerun validateOnly. DISTINCT/GROUP BY in compiled SQL and DISTINCTCOUNT measures do not repair a non-unique pk(...) lookup
  • Example: Declared DML dataset dimension is not unique in dataset 'Order Line' on this connection at validation time.

VALIDATION_QUERY_FAILED

  • Category: EXECUTION
  • Code: VALIDATION_QUERY_FAILED
  • Common Causes: Validation query failed to execute
  • Suggested Fixes: Check connection configuration and database accessibility
  • Example: Validation query failed: Connection refused

Workspace/Operation Errors

NO_WORKSPACE

  • Category: BLOCKED
  • Code: NO_WORKSPACE
  • Common Causes: No workspace folder is set or workspace is not accessible
  • Suggested Fixes: Set workspace folder or check workspace permissions
  • Example: No workspace folder configured

INVALID_PARAMS

  • Category: VALIDATION
  • Code: INVALID_PARAMS
  • Common Causes: Invalid parameter name or value
  • Suggested Fixes: Fix parameter name or value, check valid options for the parameter
  • Example: Invalid parameter: 'invalid_param'. Valid options: ['param1', 'param2']

FILE_EXPORT_ERROR

  • Category: EXECUTION
  • Code: FILE_EXPORT_ERROR
  • Common Causes: Failed to export data to file
  • Suggested Fixes: Retry with overwrite enabled, check file path and permissions
  • Example: File export failed: Permission denied

General Errors

UNEXPECTED_ERROR

  • Category: INTERNAL
  • Code: UNEXPECTED_ERROR
  • Common Causes: Unexpected internal error occurred
  • Suggested Fixes: Report this error to the development team
  • Example: Unexpected error: NullPointerException

Protocol Errors (JSON-RPC)

METHOD_NOT_FOUND

  • Code: -32601
  • Common Causes: Requested method does not exist
  • Suggested Fixes: Check available tools and use a valid method name
  • Example: Method not found: unknown_tool. Available tools: [list_connections, list_models, run_query, explain_change]

INVALID_PARAMS

  • Code: -32602
  • Common Causes: Invalid parameters for the requested method
  • Suggested Fixes: Check parameter names and valid options for the method
  • Example: Invalid params: missing tool name. Valid options: [list_connections, list_models, run_query, explain_change]

INVALID_REQUEST

  • Code: -32600
  • Common Causes: Invalid JSON-RPC request format
  • Suggested Fixes: Check request format follows JSON-RPC 2.0 specification
  • Example: Invalid Request: missing method

PARSE_ERROR

  • Code: -32700
  • Common Causes: Failed to parse JSON-RPC request
  • Suggested Fixes: Check JSON syntax and encoding
  • Example: Parse error: Invalid JSON

INTERNAL_ERROR

  • Code: -32603
  • Common Causes: Internal JSON-RPC error occurred
  • Suggested Fixes: Report this error to the development team
  • Example: Internal error

Error Details Structure

Errors may include additional structured details in the error.details field:

{
  "error": {
    "code": "COMPILE_ERROR",
    "message": "Compilation failed — see details.compilationErrors",
    "details": {
      "compilationErrors": ["error message 1", "error message 2"],
      "generatedSql": "SELECT AGG(sales) FROM MODEL WHERE dt_month = '2025-01-01'",
      "dimensionErrors": {
        "datasetA": "Dimension is not unique"
      },
      "executionErrors": ["execution error message"],
      "validationErrors": ["validation error message"]
    }
  }
}

Diagnostic metadata (error.details)

Internal recovery hints (when present) use unified names:

Field Meaning
exampleModel Suggested value for params.model on retry
exampleModelCandidates Multiple candidate model dirs/files (truncated list)
exampleModelCandidatesTotal Total candidates when list is truncated
recovery Recovery class: needs_model, needs_qualified_from, needs_both
overlapSuggestedPath Workspace overlap hint when a path was resolved incorrectly (not the model tool param)

Next Actions

Errors may include actionable next steps in the structuredContent.next.actions field:

{
  "next": {
    "actions": [
      {
        "type": "provide_model",
        "description": "Provide model (directory or .dml file) for a DML model query and retry",
        "params": {
          "model": "sql"
        }
      },
      {
        "type": "list_models",
        "description": "Run list_models first, then use the parent directory of a modelFiles entry as run_query.model"
      },
      {
        "type": "increase_timeout",
        "description": "Increase timeout value",
        "params": {
          "timeoutSeconds": 60
        }
      }
    ]
  }
}

Diagnostics warning types (non-fatal)

These appear in structuredContent.diagnostics.warnings[] (especially explain_change discovery). They use field type (not legacy EXPLAIN_* codes). They do not set isError: true.

type Meaning Agent action
missing_dimensions dimensions omitted; driver SQL not executed Pick axes from candidateDimensions and rerun with dimensions
missing_formula formula omitted; factor attribution not executed Add formula when factor breakdown is needed
REPEATED_DISCOVERY_CALL (P2, optional) Same discovery params sent again Stop looping; enter full execution with dimensions

Observations (same diagnostics object, field type): quality/context signals such as narrow_dimension_breakdown, results_truncated — not blockers; see explain-change.md §5.
