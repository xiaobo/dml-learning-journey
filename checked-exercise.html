下载与前提 #

下载可复现练习。你需要已有的 dmlc.exe、Python 和 duckdb==1.5.5。压缩包不含编译器或第三方运行时。解压到一个新的可写目录，脚本只在该目录创建练习库及配置，不连接业务数据库。

py -m pip install duckdb==1.5.5
py verify.py C:/path/to/dmlc.exe

已有 practice.duckdb 时脚本停止；再次复现请重新解压到新目录。脚本保存版本、编译器 SHA-256、退出码、诊断及执行结果。

应看到什么？ #

compile、validate、execute 退出码均为 0，最后 result_matches 为 true。脚本独立检查行数、唯一地区键、列集合、NULL 和未格式化数值。
