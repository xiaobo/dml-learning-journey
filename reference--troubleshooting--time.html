Time context pitfalls

These entries cover period values, comparison context, and missing history. Evaluation semantics owns the time-context contract.

P29. Non-first-day time filters

Wrong: dt_month = '2024-01-15' or dt_month = 'Jan 2024'. Fix: dt_month = '2024-01-01' — always first day.

P30. Missing current day in past-N-days

Wrong: dt_date BETWEEN date(current_date, '-7 days') AND date(current_date, '-1 day'). Fix: dt_date BETWEEN date(current_date, '-6 days') AND date(current_date) — 7 days including today.

P31. Including current period in past-N-months

Wrong: dt_month BETWEEN date(current_date, 'start of month', '-12 months') AND date(current_date, 'start of month'). Fix: dt_month BETWEEN date(current_date, 'start of month', '-12 months') AND date(current_date, 'start of month', '-1 month') — exclude current (incomplete) month.

P32. Using ytd modifier with full-period GROUP BY

Wrong: SELECT dt_year, AGG(sales, 'ytd') FROM MODEL GROUP BY dt_year. Fix: ytd is cumulative. Use dt_date grain: SELECT dt_date, AGG(sales, 'ytd') FROM MODEL WHERE dt_date = date(current_date) GROUP BY dt_date.

P33. Period-to-date with date range

Wrong: WHERE dt_date BETWEEN date(current_date, 'start of year') AND date(current_date) for YTD. Fix: WHERE dt_date = date(current_date) with AGG(sales, 'ytd') — modifier handles the range.

P59. YoY without column probe

Wrong: AGG(销售额, 'yoy') when 去年同期出厂价金额 sums to zero. Fix: Detail query SUM(去年同期出厂价金额) before promising YoY narrative.
