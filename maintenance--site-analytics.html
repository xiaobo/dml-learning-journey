Read the website analytics

The published tutorial and supporting HTML guides use Google Analytics 4 property G-MVE2VY7REB. The measurement ID is public; no API secret belongs in the website.

Check collection

  1. Open the published website at https://xiaobo.github.io/dml-learning-journey/.
  2. Choose Allow statistics in the optional analytics panel. Local previews never load Google Analytics. Browsers requesting Do Not Track or Global Privacy Control are excluded.
  3. Open the property's Realtime report in Google Analytics and look for the visit. An ad blocker or network restriction can prevent collection.
  4. Complete a previously unfinished chapter and inspect the chapter_complete event. Reloading saved progress and checking an already completed answer do not send another completion.
  5. Click Analytics settings in the footer to change the choice. Declining disables future measurement and removes this tutorial's prefixed analytics cookies; lesson progress remains intact. It does not erase events already collected.

Visitor and session numbers cover measured browsers that allow analytics. They are not a census of all readers or distinct people. Do not treat a pageview as a unique visitor.

Event Meaning Properties

tutorial_review Click the entry link after the course is complete course_language
chapter_view Reach a chapter; once per chapter per document load chapter_id, chapter_number, course_language
chapter_complete Newly complete a chapter; once per chapter per document load chapter_id, chapter_number, course_language
tutorial_complete Newly reach all twelve completed chapters course_language
language_change Change the tutorial language previous_language, course_language
tutorial_download Request a query, model, or checked project download download_type, course_language

Downloads count clicks, not proof that the file finished downloading. Completions indicate passing these exercises, not independently verified DML proficiency. A learner who starts collecting midway through the course may have a completion event without earlier measured chapters.

In Admin → Custom definitions, register event-scoped dimensions for chapter_id, course_language, and download_type to use these properties in breakdown reports. Use tutorial_complete as a key event if course completion is the goal.

Compare chapter reach with chapter completion to identify possible drop-off. Check language and device breakdowns before changing a chapter: low completion can also mean a returning learner, a short visit, or unmeasured activity.

Keep event counts distinct

The integration leaves ordinary page_view collection to Google's tag. It does not send manual pageviews for chapter changes. Chapter activity is recorded as the separate chapter_view event.

GA4 Enhanced Measurement can also generate pageviews from browser history changes. If the desired definition is one pageview per document load, disable Page changes based on browser history events under the Web stream's Enhanced Measurement pageview settings. The code cannot override that property-level setting with send_page_view: false alone.

Enhanced Measurement may independently record downloads as file_download. Use tutorial_download for this site's explicitly classified downloads; do not add the two event totals together.

Preserve collection boundaries

The integration loads only on HTTPS under xiaobo.github.io/dml-learning-journey/, after a visitor allows statistics. It does not queue activity from before that choice. It sends no chosen answer, model text, report contents, account ID, or complete referrer URL. Referrers are reduced to their external origin; page query strings and fragments are omitted from the configured location. Google may still derive browser/device and session information using its tag and analytics cookies.

Google Signals and ad personalization signals are disabled; advertising consent categories are denied. This integration does not insert advertisements. Analytics uses a dmljourney cookie prefix to keep its cookies separate from other projects on the same host.

Run these checks before deployment:

node dml-dmx/scripts/check-visual-analytics.cjs
node dml-dmx/scripts/check-visual-locales.cjs
node dml-dmx/scripts/check-docs.cjs

The analytics check simulates the tag queue without transmitting test events to Google.
