Website analytics status

Visitor analytics is disabled. The tutorial and supporting HTML guides load no analytics tags, send no learning events to an analytics service, and display no analytics consent panel. Google Analytics has been removed; no replacement service is configured.

The tutorial keeps learning progress and the chosen language in the visitor's browser. These functional preferences are not uploaded. Returning to the updated tutorial removes its old analytics choice and dmljourney_ cookies without changing progress, language, or unrelated cookies.

Removing the website integration does not delete previously collected data from the former analytics account. GitHub Pages hosting and its infrastructure are separate from the removed website analytics.

Check the source and a fresh publication bundle before deployment:

node dml-dmx/scripts/check-visual-analytics.cjs
node dml-dmx/scripts/check-visual-analytics.cjs .scratch/dml-learning-journey-no-analytics

The check verifies that no analytics tags or event collectors remain, and that cleanup preserves learning preferences and unrelated cookies. It sends no network requests.
