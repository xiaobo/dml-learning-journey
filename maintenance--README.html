For the published tutorial's traffic and learning events, see Read the website analytics.

Keep one mode per page. Link to the owning reference instead of copying its tables into guides or explanations. SQL and YAML queries have separate references because their fields and syntax differ. Measure declarations, measure design, and measure examples also have separate owners.

Use task names for guides and topic names for references. Use descriptive links instead of section numbers. Keep existing business identifiers and P identifiers unchanged.

Preserve existing links

The former pages under 01-concepts/, 02-syntax/, 03-workflows/, and references/ contain forwarding links to the maintained topics. Their old section anchors remain available. Update those forwarding links when moving a topic again. New links must point directly to the maintained page.

The fixture directory remains references/verification/ because the probe runner reads it directly. Its README forwards to Verify the reference.

Packaged resources

The driver's Maven resource configuration packages them from this directory. SchemaDriftTest checks source paths and resource bytes. The embedded Chinese expression help is a compiler resource; the maintained English reference is DMX expressions and functions.

Verify a documentation change

From the skills workspace, check local links, section anchors, heading hierarchy, pitfall IDs, and tutorial fixture consistency:

node dml-dmx/scripts/check-docs.cjs

For a behavior claim, run the compiler probes against the selected executable:

node dml-dmx/scripts/verify-reference.cjs dml-dmx/scripts/dmlc-mcp/dmlc.exe

Record the executable identity, complete inputs, diagnostics, and emitted SQL in release evidence. Keep compile observations, live validation, and result parity as separate claims. Record expected findings and known defects explicitly. Keep proposals in the improvement plan and retain dated observations in the archive.

YAML examples use spaces because YAML rejects tabs in indentation. Other indented code examples use tabs. English is the primary documentation language. Retain business identifiers in their original spelling.
