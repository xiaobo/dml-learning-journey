Compile your first model query

We will build a sales model and compile a query that returns totals by region. We need the bundled dmlc.exe and a writable working directory. This tutorial compiles SQL without a database connection.

Identify the compiler

First, open PowerShell in the dml-dmx directory. Save the executable path before moving to a new directory.

$dmlc = (Resolve-Path scripts/dmlc-mcp/dmlc.exe).Path
& $dmlc --version

The output includes the version, build timestamp, and platform. The tutorial compiler record identifies the build used to check this tutorial.

Now, create a new directory for our files.

New-Item -ItemType Directory -Path first-query
Set-Location first-query

The prompt now ends in first-query.

Define the model

Save the following content as model.dml.

FACT_SALES:
  type: dataset
  table: TABLE_SALES
  dimension: [id]
  columns:
    id:
    region:
    amount:
  measures:
    sales: SUM({amount})
    cnt: COUNT(1)

average_sale:
  type: measure
  formula: 'DIVIDE({sales}, {cnt})'

FACT_SALES declares one source row per id. sales and cnt aggregate those rows. average_sale divides their results.

Now, lint the model.

& $dmlc --lint model.dml --output-format=json
$LASTEXITCODE

The process exits with 0. If lint reports a finding, compare the saved file with the model above before continuing.

Write the query

Save the following content as query.sql beside model.dml.

SELECT region, AGG(sales), AGG(average_sale)
FROM MODEL
GROUP BY region

FROM MODEL selects model.dml. Each result row represents one region.

Compile the query

Now, compile the query in strict mode.

& $dmlc --compile --strict query.sql --model=model.dml --output-format=json --output-dir=gen
$LASTEXITCODE

The JSON reports status: passed, exitCode: 0, and an empty diagnostics array. artifacts.sql contains SUM(amount), COUNT(1), and GROUP BY region. The final projection contains region, sales, and average_sale.

The compiler may include a DATASET_GRAIN_UNVERIFIED note. We have compiled the declared model without checking a physical TABLE_SALES table.

Inspect the result

Open the SQL artifact under gen. Find the aggregate expressions and the grouping by region. We now have a complete model and consumer query, with generated SQL to inspect.
