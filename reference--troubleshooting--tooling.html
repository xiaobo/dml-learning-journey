Compiler and tool pitfalls

These entries cover validation, CLI capture, dialects and model filenames. Compile and validate owns the command workflow.

P34. Not running validateOnly before trusted use

Wrong: Writing a query and immediately running it without validation when database validation is available. Fix: Run --validate-only on the intended connection before trusted use. It catches compile errors, checks complete dataset dimensions reached by the query against observed data, and probes the main query with EXPLAIN; it does not prove result correctness or future uniqueness. Prerequisite: Validation requires an executable with --validate-only and a configured connection. Check --help and --advanced-help. If either prerequisite is missing, record database validation as not run. See live validation.

P35. Ignoring column descriptions

Wrong: Using customer_name when description says "internal use only, use customer instead". Fix: Read and follow column descriptions. Replace internal fields with their public aliases.

P36. Mismatched dialect

Wrong: Using SQLite-style date() functions in an MSSQL model. Fix: Match your macro file and date functions to the target dialect.

Category: Compiler, YAML, and naming

P53. PowerShell && chaining

Wrong: cd path && dmlc --model=model.dml query.sql Fix: cd path; dmlc --model=model.dml query.sql

P53b. FROM name ≠ --model= file name

Wrong: dmlc q.sql --model=acme.dml with SQL SELECT AGG(x) FROM MODEL
→ model file "acme.dml" does not match FROM "MODEL" (expected "MODEL.dml") (exit 65).
Fix: Change to FROM acme; or use --model=model.dml / keep FROM MODEL; or pass the directory that contains the right .dml (--model=<dir> finds <FROM>.dml inside).
Note: dmlc -e rejects directories — it needs a .dml file. See Model Query SQL §"Query types".

P63. / operator in inline CLI Model Query SQL on Windows

Symptom: file not found: SELECT ... — the / in a / b makes the CLI treat the SQL string as a file path. Fix: use DIVIDE(a, b) in inline CLI invocations, or pass the query via a .sql file instead of a command-line argument.

P54. CJK JSON via PowerShell pipe

Wrong: dmlc ... | Out-File result.json or capturing stdout for Chinese field names. Fix: dmlc ... -o result.json --overwrite or Node execSync(..., { encoding: 'utf8' }).
