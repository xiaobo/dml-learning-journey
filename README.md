# A small journey through DML

A twelve-chapter interactive tutorial with English, Chinese, Japanese and German language switching.

Open `index.html` through a static web server, or enable GitHub Pages from the main branch and repository root. All exercises run in the browser using invented data. No backend, database connection, build step or secrets are required. Learning progress stays in each visitor's browser.

The linked documentation is included as HTML. The downloadable lesson project retains its DML, SQL, CSV and compiler evidence. Compiler executables and unrelated workspace files are excluded.
