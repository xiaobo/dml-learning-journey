datoml表达式说明

  1. 维度、指标引用:

    • 引用指标和所属数据集中的列：{指标名}，{列名}
    • 引用关联数据集中的列：
      • {dataset名称}.列名 (通过关联数据集的主键列和本数据集中的同名列关联)
      • pk({列1}, {列2}).{dataset名称}.列名 (指定本数据集中的关联列名)
    • 引用关联表中的字段：pk({列1}, {列2}).表名(主键字段1，主键字段2).字段
    • DMX 运行时变量：
      • {dim_dt} — 当前查询的时间维度；运行时解析为 dt_date、dt_week、dt_month、dt_quarter 或 dt_year，也可作为维度修饰符参数。也可直接使用 {dt_date} / {dt_week} / {dt_month} / {dt_quarter} / {dt_year}
      • {measure} — fn-macro 的调用指标占位符；宏展开时替换为调用方正在修饰的指标，仅在 fn-macro 的 formula 中使用
    • 指标作维度：把命名指标放进 columns.dimension，按算出的标签分组（获客月、分层等）。使用处必须写 {标签: {+d: 实体}}（或 dimension:）；运行时先在实体层级计算标签和指标，然后再将指标聚合到标签层级

  2. 指标修饰：{指标名: 修饰符}

    • 维度修饰符：对指标维度进行调整（+d，-d）或指定（dimension）后引用；

      • +d: dim — 维度下钻：在「查询粒度 ∪ {dim}」上求值；滚回查询粒度须显式外层聚合（指标作维度的标签绑定除外）
      • -d: dim — 维度上卷：从查询维度移除指定维度，获取更粗粒度上的指标聚合值（筛选仍可下推）
      • -df: dim — 维度上卷并阻断筛选：去掉该维分组，并阻断该维相关筛选下推
      • -f: name — 仅移除筛选：从度量求值中去掉指定名称或列相关的筛选；不改变分组。查询级筛选仍约束报表行集
      • dimension: [dims] — 替换维度集：用指定维度列表替换后获取指标值
      • 禁止同一修饰对象内 +d 与 -d/-df 维名相交（会编译报错）；不同维可共存

    • 业务限定修饰符: 为指标添加额外的筛选条件

      • +f: condition — 添加筛选条件：在计算指标值时额外添加筛选

    • 修饰符可叠加使用，遵循从左到右的生效顺序：

      • e.g. AGG({sales: {ytd, ya}}) / AGG(sales, 'ytd', 'ya') 等价于 当年至今累计的去年同期值
      • 语法格式为AGG(指标名, 修饰符1, 参数1(可选), 修饰符2...)或AGG({指标名: {修饰符1: 参数1(可选), 修饰符2}})

    • 时间修饰符（dt-macro，返回绝对值）：

      • dim_dt — 时间维度引用：会落地到查询中的实际时间相关列，支持通过 as hour/date/week/month/quarter/year 进行期间类型转换
      • ytd: 当年至今 (year-to-date), 支持的时间维度包含日，月，季
      • qtd: 当季至今 (quarter-to-date), 支持的时间维度为日，月
      • mtd: 当月至今 (month-to-date), 支持的时间维度为日
      • wtd: 当周至今 (week-to-date), 支持的时间维度为日
      • mat: 滚动年度总计 (moving annual total)
      • ya: 去年同期 (year ago)
      • pp: 上期值（last period）, 可作为上季度last quarter，上月last month等
      • ppp: 上上期（上上季度，上上月）
      • p3m: 过往3个月，含当月（共3个月） (previous 3 month)
      • p6m: 过往6个月，含当月（共6个月） (previous 6 month)
      • p2y: 过往2年，含当期 (previous 2 year)
      • p3y: 过往3年，含当期 (previous 3 year)
      • p5y: 过往5年，含当期 (previous 5 year)

    • 增长率修饰符（fn-macro，返回小数）：

      • yoy: 同比增长率 (year-over-year)：divide({measure}*1.0, {measure: ya}) - 1，返回小数
      • pop: 环比增长率 (period-over-period)：divide({measure}*1.0, {measure: pp}) - 1，返回小数
      • mom: 月环比增长率 (month-over-month)，pop在月粒度的别名

    • 函数修饰符（fn-macro）：

      • firstday: 期初值 (period opening value)，指标在期间第一天的值
      • lastday: 期末值 (period closing value)，指标在期间最后一天的值
      • lastmonth: 当前期间内最后一月
      • grand: 总计，丢弃所有维度：{measure: {dimension: []}}
      • pot: 占总计百分比 (percentage of total)：divide({measure}*1.0, {measure: grand})
      • rank: 降序排名 (rank descending)，1 = 最大值
      • rank_asc: 升序排名 (rank ascending)，1 = 最小值
      • today: 今日值
      • yesterday: 昨日值
      • current_month: 当月值

  3. 期间相关：

    • 使用期间的第一天指代整个期间
    • 期间字段名通常使用dt_date/dt_month/dt_quarter/dt_year代表完整期间，模型中只需定义一个期间字段，系统会自动生成其他后续期间字段定义而无需手动定义
    • 当引用指标时使用了时间修饰符，需要可解析的期间上下文并满足宏的 prerequisite；查询维度或期间筛选均可提供上下文
    • 时间筛选条件使用目标期间即可，无需包含时间修饰符指定的期间，比如当使用pop时，指定当期即可，无需在筛选条件中包含上期，使用yoy时，也无需在筛选条件中包含去年同期

  4. 使用datoml函数：

    • AGG(指标名): 返回指标值，指标名可以在独立的DML模型文件中定义，也可以是本SQL中的聚合列，仅在查询SQL中使用，当在SQL中通过AGG函数引用指标时，如果没有指定输出字段名，则默认指标名为输出字段名
    • AGG(指标名, 修饰符, 参数...) / AGG({指标名: 修饰符}): 同上，返回修饰后的指标值，
      • 如 AGG([销售额], '+d', prod_id), AGG({销售额: {+d: prod_id}}) 均为合法表达式 ==> 注意前者写法中 prod_id 为列名，无需引号包围，也无需转义；后者写法中 prod_id 为以列名为内容的字符串，在列名中不含特殊字符的情况下，可以无需引号包围，否则需要引号包围，且内部特殊字符需要转义
      • 如 AGG([销售额], '+f', prod_id = '1'), AGG({销售额: {+f: 'prod_id = ''1'''}}) 均为合法表达式 ==> 注意前者写法中 prod_id = '1' 为筛选表达式，无需引号包围，也无需转义；后者写法中 prod_id = '1' 为以筛选表达式为内容的字符串，需要引号包围，且内部特殊字符需要转义
    • DIVIDE(分子表达式, 分母表达式): 安全除法并使用浮点数格式，在分母表达式值为0时返回NULL, 相当于 分子表达式*1.0 / nullif(分母表达式, 0)
    • DISTINCTCOUNT(表达式): 排重计数，相当于 count(distinct 表达式)
    • SUMIF(表达式, 条件): 条件求和，相当于 sum(case when 条件 then 表达式 end)
    • COUNTIF(条件): 返回满足条件的行数，相当于 count(case when 条件 then 1 end)
    • COUNTIF(表达式, 条件): 统计满足条件且表达式值不为NULL的行数，相当于 count(case when 条件 then 表达式 end)
    • DISTINCTCOUNTIF(表达式, 条件): 条件排重计数（不含NULL，多行值相同记为一行），相当于 count(distinct case when 条件 then 表达式 end)
    • AVGIF(表达式, 条件): 条件平均，相当于 avg(case when 条件 then 表达式 end)
    • MAXIF(表达式, 条件): 条件最大值，相当于 max(case when 条件 then 表达式 end)
    • MINIF(表达式, 条件): 条件最小值，相当于 min(case when 条件 then 表达式 end)

  5. 支持sqlite-style的date函数:

    • date(表达式, 修饰字符串, 修饰字符串, ...), 支持如下修饰字符串:
      • NNN day(s)/week(s)/month(s)/quarter(s)/year(s): 取所在日期的后N天/星期/月/季/年，当N为负数时，取所在日期的前N天/星期/月/季/年
      • start of week/month/quarter/year: 取所在星期/月/季/年的第一天，其中星期的第一天为星期一
      • weekday N: 取所在星期的第N天，其中N=1时为星期一，N=7时为星期日
