DML and DMX documentation

DML defines datasets and reusable business measures in YAML. Model Query consumes those definitions. DMX supplies expressions and modifiers in both contexts.

SKILL.md routes agent tasks. Start with the first-query tutorial, or use the task and topic indexes below.

For a complete beginner project, follow the interactive DML tutorial: twelve illustrated chapters, graded exercises, saved progress, and a downloadable regional report. The shorter visual introduction explains the basic concepts.
