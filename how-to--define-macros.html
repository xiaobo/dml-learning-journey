Define a custom macro

Use a custom macro to reuse a time transformation or a formula over a caller-selected measure. Read the modifier reference for invocation and composition rules.

Custom macro definitions (dt-macro and fn-macro)

Users can define their own macros in .dml — both dt-macro (time-range shifts) and fn-macro (formula wrappers). Define once, reference by name in any measure or query, just like built-in modifiers.

Two macro types:

Type Purpose Key property {measure} placeholder
dt-macro Shift/expand the time window value: (single-point shift) or range: [start, end] No — operates on time context
fn-macro Wrap the measure in a derived formula formula: using {measure} Yes — replaced by the caller's measure

Custom dt-macro examples:

p4w:
  type: dt-macro
  description: Past 4 weeks (including current)
  range:
    - date({dim_dt}, '-3 weeks')
    - '{dim_dt}'

p3y:
  type: dt-macro
  description: Past 3 years
  range:
    - dateadd({dim_dt.datetype}, 1 - {dim_dt.periods_per_year} * 3, {dim_dt})
    - '{dim_dt}'

Custom fn-macro examples:

# Average per period: roll up to time grain, divide by distinct periods
avg_p_dt:
  type: fn-macro
  formula: |-
    SUM({measure: {+d: dim_dt}}) / COUNT(DISTINCT {dim_dt})

# Average over past 3 periods (stacks avg_p_dt with custom dt-macro p3p)
p3p_avg:
  type: fn-macro
  formula: |-
    {measure: {avg_p_dt, p3p}}

# User-defined growth rate (same shape as built-in pop)
my_pop:
  type: fn-macro
  description: User-defined period-over-period growth rate
  formula: |-
    divide({measure}, {measure: pp}) - 1

Usage in measures:

P4W_active_customers:
  type: measure
  description: Active customers in past 4 weeks
  formula: '{active_customers: p4w}'

weekly_avg_sales_4w:
  type: measure
  formula: 'DIVIDE({sales: p4w}, IIF({weeks_since_launch} >= 3, 4, {weeks_since_launch} + 1))'

avg_sales_3p:
  type: measure
  formula: '{sales: p3p_avg}'

Key points:

  • dt-macro: use value: for single-point shifts or range: for [start, end] date ranges. {dim_dt} resolves to the query's current time dimension; {dim_dt.datetype} to its type string ('week', 'month', etc.); {dim_dt.periods_per_year} gives periods per year (52 for weeks, 12 for months, 4 for quarters).
  • fn-macro: use formula: with {measure} as placeholder for the caller's measure. Can stack other macros inside: {measure: {avg_p_dt, p3p}} applies avg_p_dt to the result of p3p time shift.
  • Reference custom macros the same way as built-in modifiers: {measure: p4w}, {measure: my_pop}, or AGG({sales: p3p_avg}).
  • prerequisite: optionally constrains grain validity (e.g. only valid at month grain).
