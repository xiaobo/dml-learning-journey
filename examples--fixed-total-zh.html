只显示一月时，分母应保留哪些月份？

-d 保留月份筛选，-df 在该指标计算中移除它。 两者都可以只输出一月，分母计算范围与报表输出行范围需要分别检查。

用同一份数据比较 #

地区 a 一月销售10、二月20；地区 b 一月销售30。筛选一月后：

地区 月份 销售额 -d 地区总额 -df 地区总额
a 2024-01-01 10 10 30
b 2024-01-01 30 30 30

因此 a 的占比可以是10/10，也可以是10/30；需要由业务口径决定。未筛选月份时，两种地区总额都是30，a 的一月、二月各占自己的销售额。

保存两种口径，再改变查询 #

模型定义 region_selected: '{sales: {-d: month}}' 和 region_all_months: '{sales: {-df: month}}'。本例 month 是普通字符串字段，值按 ISO 日期排列，不是自动时间上下文 dim_dt。

完整文件 / Complete file: fixed/model.dml 
dialect: duckdb
F:
  type: dataset
  table: FACT
  dimension: [id]
  columns:
    id:
    region:
    month:
    amount:
  measures:
    sales: SUM({amount})
region_selected:
  type: measure
  formula: '{sales: {-d: month}}'
region_all_months:
  type: measure
  formula: '{sales: {-df: month}}'
running_sales:
  type: measure
  formula: 'SUM({sales}) OVER (ORDER BY {month} ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)'
  dimensions:
    - [month]
完整文件 / Complete file: fixed/setup.sql 
CREATE TABLE FACT(id INTEGER,region VARCHAR, month VARCHAR,amount INTEGER); INSERT INTO FACT VALUES (1,'a','2024-01-01',10),(2,'a','2024-02-01',20),(3,'b','2024-01-01',30);
完整文件 / Complete file: fixed/january.sql 
SELECT region, month, AGG(sales), AGG(region_selected), AGG(region_all_months) FROM MODEL WHERE month='2024-01-01' GROUP BY region,month ORDER BY region,month
完整文件 / Complete file: fixed/unfiltered.sql 
SELECT region, month, AGG(sales), AGG(region_selected), AGG(region_all_months) FROM MODEL GROUP BY region, month ORDER BY region,month

模型不变，查询决定报表显示哪些月份。验证器比较所有列与完整行集合，确保 -df 没有把二月输出行带回来。

哪些结论不能直接推广？ #

这里是已知的地区、月份分组，不是动态透视轴或自动小计 API。普通字段的结果也不能代替对 dim_dt 时间粒度移除的验证。对于时间查询，先看累计 KPI 的上下文，不要照搬字段替换。

运行与验证范围 #

下载完整项目，按包内 README.md 运行 verify.py。需要已有的 dmlc、Python 和 DuckDB；脚本只在你指定的全新输出目录创建练习库。所有案例共用一个入口，结果与诊断保存在输出目录。

本例在 dmlc 0.3.16、2026-11-13 构建的 DuckDB 连接上验证。编译器指纹、用例列表和状态见包内 verification-summary.json。数据库验证和随后执行是独立操作，不保证同一快照。其他引擎需单独验证。
