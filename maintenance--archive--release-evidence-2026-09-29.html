Reproduce

Run the verification suite. It contains 29 complete cases, a manifest, diagnostic/SQL assertions and an explicit known-defect category. The command for a DML case is:

dmlc.exe --compile --strict report.dml --output-format=json --output-dir=gen

For SQL cases, replace report.dml with query.sql and add --model=model.dml. Run inside a copy of the case directory so generated artifacts remain separate from reference sources. The runner does this automatically and preserves process output plus command arguments.

Open compiler defects

  1. Count classifier accepted with invalid SQL. label_plus/report.dml classifies by {cnt: {+d: customer}}, with cnt: COUNT(1). Strict compilation exits 0 with empty diagnostics and emits GROUP BY COUNT(1). This is invalid MSSQL. A zero exit is insufficient; this shape is not a publishable supported example.
  2. Replacement-dimension classifier lowering fails. label_dimension/report.dml uses {cnt: {dimension: [customer]}}. The entity-key check accepts the form, but compilation exits 2 with generated nullpk() syntax and a parse diagnostic. Recognition of the syntax does not establish end-to-end support.
  3. Same-dimension +d/-d/-df intersection may still be accepted or algebraically rewritten on older builds — language contract is fail-loudly; track until a structured diagnostic exists.

The documentation changes do not fix these compiler defects. Keep their inputs and observed outcomes when reporting them upstream. Materialize classifiers, broader temporal classifiers and complete dialect parity remain outside this verification scope. The improvement plan records future requirements separately.

Publication boundary

Publish this material as a versioned reference with these limitations visible. Claims of exhaustive correctness, universal fail-closed behavior or all examples being verified would exceed the evidence. Refresh schema/macro reference copies from the intended release resources before a release upgrade; changing a copied schema alone cannot change the distributed binary.
